# OpenLife — Research Cards

> กฎ: **ห้าม implement เนื้อหา/แผนที่/ระบบที่อิงโลกจริงก่อนมี research card**
> ดูรายละเอียดกฎใน `AGENTS.md` §0

## วิธีใช้
1. สร้างไฟล์ `<province>-<district>.md` หรือ `<topic>.md`
2. กรอกหัวข้อขั้นต่ำ 9 ข้อ (ดู template ล่าง)
3. ใส่ URL + วันที่เข้าถึง + ข้อเท็จจริง + ข้อสงสัย
4. อัปเดตตารางสถานะด้านล่าง
5. ถ้าข้อมูลไม่พอ: `TODO(research)` — ห้ามแต่งเป็น fact

## Template

```md
# <ชื่อจังหวัด> — <ชื่อเขต/หัวข้อ>

## 1. คำถามที่ต้องตอบ
## 2. ข้อเท็จจริงหลัก
## 3. ภูมิศาสตร์ / แผนที่
## 4. เศรษฐกิจ / อาชีพ / ราคา
## 5. วัฒนธรรม อาหาร ผู้คน ภาษา
## 6. ปัญหา / ความอ่อนไหว
## 7. ไอเดียสำหรับเกม
## 8. สิ่งที่แต่งเพิ่ม (fictionalized)
## 9. แหล่งอ้างอิง
```
