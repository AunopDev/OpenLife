# กรุงเทพมหานคร — สีลม / เขตบางรัก

เข้าถึงข้อมูล: 2026-11-10

## 1. คำถามที่ต้องตอบ
- สีลมอยู่ในเขตไหน มีขนาด/ประชากรเท่าไร
- เศรษฐกิจหลักและสถาปัตยกรรมเป็นแบบไหน
- landmark/ระบบขนส่งจริงมีอะไร
- ชีวิตกลางวัน/กลางคืนต่างกันอย่างไร
- แผนที่ CBD 40×28 ควรมีตึกสูง/ถนนกว้าง/skywalk/ตรอกอาหารแค่ไหน

## 2. ข้อเท็จจริงหลัก
- สีลมอยู่ในเขตบางรัก ฝั่งพระนครของกรุงเทพฯ
- เขตบางรักพื้นที่ 5.54 ตร.กม. ประชากร 42,921 คน (ธ.ค. 2566) แบ่ง 5 แขวง
- บางรักเป็นย่านเศรษฐกิจเก่าแก่ มีสถานทูต/โรงเรียน/โรงแรม/อาคารสำนักงาน และย่านสีลมเป็นหนึ่งในพื้นที่มูลค่าที่ดินสูงที่สุดในไทย
- ถนนสีลมเป็นแกนหลักของ CBD มีทั้งสำนักงาน ธนาคาร โรงแรม โรงพยาบาล โรงเรียน และไนท์ไลฟ์
- พัฒน์พงศ์เป็นย่านสถานบริการที่รู้จัก; เขตมีคำขวัญเรื่อง “โซนนิงสถานบริการ”
- เขตบางรักมีมรดกสถาปัตยกรรมตะวันตก/โคโลเนียล เช่น อาสนวิหารอัสสัมชัญ, อาคารไปรษณีย์กลาง, ศุลกสถาน, อาคารอีสต์เอเชียติก
- ถนนเจริญกรุงได้รับส่งเสริมเป็นย่านธุรกิจสร้างสรรค์ “สร้างสรรค์เจริญกรุง”

## 3. ภูมิศาสตร์ / แผนที่
- ทิศเหนือ/ตะวันออก: ปทุมวัน (ถนนพระรามที่ 4)
- ทิศใต้: สาทร (คลองสาทร)
- ทิศตะวันตก: คลองสาน (แม่น้ำเจ้าพระยา)
- ทิศตะวันตกเฉียงเหนือ: สัมพันธวงศ์ (คลองผดุงกรุงเกษม)
- ถนนหลัก: สีลม, สาทร, พระรามที่ 4, เจริญกรุง, นราธิวาส, ราชดำริ
- ขนส่ง: BTS สายสีลม (ศาลาแดง, ช่องนนทรี), MRT สีลม, สกายวอล์กเชื่อมอาคาร
- ลักษณะ: ตึกสูงกระจก, ถนนกว้างหลายเลน, ทางเท้า, สกายวอล์ก, ตรอกอาหาร, โรงแรม, คอนโด

## 4. เศรษฐกิจ / อาชีพ / ราคา
- การเงิน/ธนาคาร/สำนักงานใหญ่บริษัท, โฆษณา, ที่ปรึกษา, โรงแรม, การท่องเที่ยว, ไนท์ไลฟ์, อาหาร
- อาชีพในเกม: พนักงานออฟฟิศ, นักการเงิน, ผู้บริหาร, พนักงานโรงแรม, พนักงานร้านอาหาร, ครีเอทีฟ, แพทย์/พยาบาล (โรงพยาบาลในย่าน)
- ที่ดิน/ค่าเช่าแพงมาก — เหมาะกับระบบ rent/salary ระดับสูง
- กลางวัน: คนทำงาน/รถติด/ร้านอาหารกลางวัน; กลางคืน: บาร์/ไนท์ไลฟ์/ตลาดกลางคืน/สกายวอล์ก

## 5. วัฒนธรรม อาหาร ผู้คน ภาษา
- ผู้คนหลากหลาย: พนักงานออฟฟิศ, ชาวต่างชาติ, นักท่องเที่ยว, ชุมชนดั้งเดิม, กลุ่ม LGBTQ+ ในย่านไนท์ไลฟ์
- อาหาร: ตรอกอาหารกลางวัน (เช่น ซอยคอนแวนต์), สตรีทฟู้ด, ร้านกาแฟ, ห้าง/ฟู้ดคอร์ท
- ศาสนสถาน: อาสนวิหารอัสสัมชัญ, วัดแขกสีลม (ศรีมหามาริอัมมัน), วัด/ศาลเจ้าตามซอย
- ภาษา: ไทย + อังกฤษในที่ทำงาน/ป้าย + ภาษาของแรงงานข้ามชาติ

## 6. ปัญหา / ความอ่อนไหว
- รถติด/มลพิษ/ทางเท้าแออัด
- ความเหลื่อมล้ำระหว่างตึกสูงกับชุมชนเล็ก/ตรอกข้างหลัง
- ไนท์ไลฟ์/สถานบริการเป็นส่วนหนึ่งจริง แต่ห้ามลดทอนสีลมเหลือแค่ภาพนั้น
- การเปลี่ยนผ่าน/gentrification ของย่านเก่า
- อย่าใช้ชื่อสถานบริการ/บุคคลจริงในทางเสียหาย

## 7. ไอเดียสำหรับเกม
- **Map spec 40×28:** grid ถนนกว้าง, ตึกสูง 3–5 ชั้นขึ้นไป (ในมุมเกม), plaza, skywalk ลอย, ตรอกอาหารแคบ, สถานี BTS/MRT, โรงแรม, โรงพยาบาล
- **Landmarks:** สกายวอล์กช่องนนทรี, คิงเพาเวอร์มหานคร, อาสนวิหารอัสสัมชัญ, ไปรษณีย์กลาง, ตลาดกลางคืนพัฒน์พงศ์
- **Activities:** ทำงานออฟฟิศ, ประชุม/นำเสนอ, กินตรอกอาหาร, เดินสกายวอล์ก, ออกกำลังกายในสวน nearby, ไนท์ไลฟ์, ตรวจสุขภาพ
- **Events:** เลย์ออฟ/โปรโมชัน, ค่าเช่าคอนโดขึ้น, ลูกค้าบริษัท, งานอีเวนต์กลางคืน, ชุมชนข้างหลังตึกถูกรื้อ, น้ำท่วมถนน, มลพิษ/PM2.5
- **Palette:** ฟ้าแก้ว/เทาเงิน, กระจกสะท้อน, ไฟนีออนกลางคืน, เขียวสวน, ทองคำใน temple
- **อารมณ์:** กลางวันเร่งรีบ กลางคืนมีสีสัน
