# ระบบ — แต่งตัวละครตอนสร้าง (Character Creator)

เข้าถึงข้อมูล: 2026-11-10

## 1. คำถามที่ต้องตอบ
- เกมแนว life sim มีตัวเลือกอะไรให้แต่งตัวละครบ้าง
- อะไรคือ “แก่น” ที่ผู้เล่นคาดหวัง และอะไรคือรายละเอียดเกินจำเป็น
- ทำอย่างไรให้ผู้เล่นทั่วไปไม่หลงในตัวเลือกจำนวนมาก
- เกม pixel-art 32×32 ควรเก็บอะไรไว้บ้าง

## 2. ข้อเท็จจริงหลัก (จากแหล่งอ้างอิง)
- Paralives Paramaker แบ่งเป็น **Appearance / Clothing / Personality** และมีหมวดย่อย: สีผิว, รูปร่าง, ทรงผม (66 แบบ), สีผม (color wheel + roots/tips), ตา (รูป/สี/heterochromia/ขนตา), คิ้ว, จมูก (16 preset), ปาก (19 preset), ฟัน, โครงหน้า/หู/กราม/คาง/แก้ม, หนวดเครา, สิว/ไฝ/กระ, เมคอัพ, รอยสัก, แว่น, ต่างหู, สร้อย, เสื้อผ้าแยกชั้น
- ระบบมีทั้ง **preset + slider** และเปิดให้สุ่มตัวละครเริ่มต้น
- งานวิจัย UX ระบุว่า freedom สูงทำให้ผู้เล่นทั่วไปสับสน จึงแนะนำ:
  - มี **โหมดง่าย/โหมดละเอียด**
  - มี preset จำนวนมาก + ปุ่มสุ่ม
  - มี reset/undo
  - ใช้ชื่อเรียกที่คนทั่วไปเข้าใจ ไม่ใช้ศัพท์กล้ามเนื้อหน้า
- Witchbrook เน้น **หลากหลายสีผิวและเนื้อผม**, แยก “ผมหน้า/ผมหลัง”, ให้ทุกทรงและเสื้อผ้าใช้ได้ทุกเพศ, และเปลี่ยนทรงผม/หนวดได้ภายหลังที่ร้านตัดผม
- แนวโน้มสำคัญ: **ไม่ล็อกตัวเลือกตามเพศ**, มีเลเยอร์เสื้อผ้า/อุปกรณ์, และให้เปลี่ยนภายหลังได้

## 3. ขอบเขตที่เกมเราเลือก (32×32 pixel portrait)
เลือกสิ่งที่มีผลต่อการมองเห็นในระยะ portrait และโลกเกม:
- สีผิว 6 เฉด
- รูปหน้า 5 แบบ (กลม/ไข่/เหลี่ยม/ยาว/สามเหลี่ยม)
- ทรงผม 11 แบบ + สีผม 10 สี
- ตา 5 ทรง + สีตา 6 สี
- คิ้ว 5, จมูก 5, ปาก 5
- หนวดเครา 5
- แว่น 5, หมวก 4, เครื่องประดับ 4
- เสื้อ 4 ทรง + สีเสื้อ 8 สี
- กระ/ไฝ เปิด-ปิด
- สุ่มทั้งชุด / รีเซ็ต / พรีวิวสด

**ยังไม่ทำรอบนี้:** body slider, ส่วนสูง, makeup, tattoo, เสื้อผ้าแยกชั้น, เปลี่ยนผมที่ร้านตัดผม (TODO)

## 4. เศรษฐกิจ / อาชีพ / ราคา
- ไม่เกี่ยวกับเศรษฐกิจโดยตรง
- อนาคต: ร้านตัดผม/ร้านเสื้อผ้าในเขตเมืองเก็บเงินค่าเปลี่ยนทรง

## 5. วัฒนธรรม อาหาร ผู้คน ภาษา
- ชื่อตัวเลือกเป็นภาษาไทยทั่วไป: “แสกข้าง”, “รองทรง”, “กะลาครอบ”, “หางม้า”
- ไม่ผูกทรงผมกับเพศหรืออาชีพ
- สีผิวมีช่วงกว้างและไม่ใช้คำเหยียด

## 6. ปัญหา / ความอ่อนไหว
- ต้องไม่ล็อกทรงผม/เสื้อผ้าตามเพศ
- หลีกเลี่ยงการล้อรูปร่างหรือสีผิว
- ตัวเลือกต้องไม่เยอะจนกดยากบนมือถือ
- ต้องมีปุ่มสุ่ม/รีเซ็ตเพื่อลดภาระการเลือก

## 7. ไอเดียสำหรับเกม
- พรีวิว 32×32 ขยายแบบ nearest-neighbour ให้เห็นพิกเซลชัด
- แท็บ 4 กลุ่ม: หน้า / ผม / ผิว / แต่งตัว
- ปุ่ม “สุ่ม” และ “ล้าง” ข้างพรีวิว
- เก็บใน `life.appearance` และใช้ทั้ง HUD portrait, ตัวละครบนแผนที่, และหมุดแผนที่
- เปลี่ยนภายหลังได้ในอนาคต (ร้านตัดผม/ร้านเสื้อผ้า)

## 8. สิ่งที่แต่งเพิ่ม (fictionalized)
- จำนวนและชื่อทรงผม/เสื้อผ้าเป็นชุดที่เกมออกแบบเอง
- สีผิว/สีผมเป็นพาเลตต์ pixel-art ไม่ใช่สีผิวจริงแบบละเอียด
- การแมปตัวเลือกกับอารมณ์/อาชีพยังไม่มีผลเชิง mechanic

## 10. สถานะ implement

- `src/appearance.ts` — ตัวละคร 32×32 + ตัวเลือก + สุ่ม + audit + ริ้วรอย/ผมเทาตามอายุ
- `src/appearance-editor.ts` — UI ใช้ร่วมทั้ง creation / กระจก / ร้านตัดผม / ร้านเสื้อผ้า
- หน้าแต่งตัวตอนสร้าง: ชื่อ/เพศ/จังหวัด → แต่งหน้าตา → เขต/อำเภอ → ย่าน → ภูมิหลัง → ความฝัน
- เปลี่ยนภายหลัง:
  - กระจกที่บ้าน ฟรี (+5 grooming)
  - ร้านตัดผม ฿300 (+20 grooming)
  - ร้านเสื้อผ้า ฿800 (+12 grooming)
- `life.grooming` 0–100 ลด 1/เดือน; มีผลกับ mood และโอกาสสัมภาษณ์
- ชุดสุภาพ (เชิ้ต/เบลาส์) +8 โอกาสหางาน, ชุดลำลอง −2
- อายุ 42+/55+/68+ มีริ้วรอย; 58+ ผมแสดงเป็นเทา
- **Wardrobe 3 ชุด** (ลำลอง/ทำงาน/ออกงาน) ใส่/บันทึกที่กระจก
- NPC reaction หลังเปลี่ยนลุค (+love/friend, +ใจ)
- **อาชีพสายบันเทิง**: นายแบบ/นักแสดง/อินฟลูเอนเซอร์ ในหน้าหางาน
- **บัตรประชาชน** ใช้ portrait/ชื่อ/ที่อยู่/อาชีพ
- ร้านตัดผมชุมชนบางขุนเทียน ฿150

## 11. ไอเดียระบบต่อยอด (ยังไม่ทำ)
- ร้านแว่น/ร้านหมวกแยก, ร้านเสริมสวยทำเมคอัพ
- ทรงผมตามแฟชั่น/ยุค และร้านตัดผมในแต่ละเขต
- บาดเจ็บ/แผลเป็น/ตั้งครรภ์เปลี่ยนรูปร่าง
- NPC ทักเรื่องลุคแบบละเอียดตามความสัมพันธ์ (ทำแล้วเวอร์ชันพื้นฐาน)
- อาชีพสายบันเทิงมีระดับชื่อเสียง/แฟนคลับ (ทำแล้วเวอร์ชันพื้นฐาน)
- ภาพถ่ายติดบัตร/บัตรประชาชน (ทำแล้ว)
- อาชีพนายแบบ/นักแสดง/ influencer ใช้ค่าความเรียบร้อยและลุค (ทำแล้ว)
