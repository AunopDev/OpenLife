# ระบบ — หน้าเมนูหลัก (Main Menu / Title Screen)

เข้าถึงข้อมูล: 2026-11-10

## 1. คำถามที่ต้องตอบ
- เมนูหลักควรมีปุ่มอะไร เรียงอย่างไร
- ควรแสดง “เล่นต่อ” ก่อนหรือ “เริ่มใหม่” ก่อน
- พื้นหลังแบบไหนเหมาะกับเกม pixel-art ชีวิตคนไทย
- ทำอย่างไรไม่ให้เมนูกลายเป็นกำแพงก่อนเข้าเกม

## 2. ข้อเท็จจริงหลัก (พร้อมอ้างอิง)
- หลัก UX เกม: เป้าหมายของเมนูคือพาผู้เล่นเข้าเกมให้เร็วที่สุด และลดจำนวนชั้นเมนู
- เมื่อมีเซฟอยู่ ควรวาง **Continue** เป็น action หลักก่อน New Game
- เมนูควรมีตัวเลือกไม่กี่อย่างและจัดกลุ่มชัด (เล่น / ตัวเลือก / ออก)
- Parallax scrolling คือการเลื่อนเลเยอร์พื้นหลังด้วยความเร็วต่างกันเพื่อสร้างมิติความลึก
- เมนูแบบ parallax + ภาพเคลื่อนไหวช่วยให้หน้าจอ title ดูมีชีวิตโดยไม่ต้องใช้ภาพวาดเพิ่ม

## 3. ภูมิศาสตร์ / บริบทภาพ
- ฉากหลังใช้กรุงเทพฯ ยามหัวค่ำ: เส้นขอบฟ้า ตึกสูง วัด/prang บีทีเอส ป้ายไฟ รถบนถนน
- อ้างอิงลักษณะจาก research cards: `bangkok-silom.md`, `bangkok-yaowarat.md`
- ใช้พาเลตต์กรมท่า/ทอง/ส้มเหมือน HUD และฉากในเกม

## 4. เศรษฐกิจ / อาชีพ / ราคา
- ไม่เกี่ยวข้องโดยตรง (เป็น UI)

## 5. วัฒนธรรม อาหาร ผู้คน ภาษา
- ข้อความบนเมนูเป็นภาษาไทย โทนจริงจังอบอุ่น ไม่ใช้คำขายของ
- ไม่ใช้ภาพจำ “ไชนาทาวน์ = อาหาร” หรือ “กรุงเทพฯ = ตึกสูงอย่างเดียว” — ใส่ทั้งวัด บ้านแถว และรถเมล์

## 6. ปัญหา / ความอ่อนไหว
- ภาพเมืองต้องไม่กลายเป็น stereotype หรือใช้ landmark ผิดตำแหน่งจริง
- หลีกเลี่ยง flashing รุนแรง; ต้องรองรับ `prefers-reduced-motion`
- ต้องไม่ขวางผู้เล่นที่กลับมาเล่นต่อ (Continue ต้องเด่น)

## 7. ไอเดียสำหรับเกม
- พื้นหลัง animated canvas 480×270 (pixel) scale แบบ nearest-neighbour
- 4 เลเยอร์ parallax: ท้องฟ้า/ดาว, skyline ไกล, skyline กลาง + BTS + วัด, ร้านแถวใกล้ + ถนน + รถ
- วงจรแสง sunset → night ช้า ๆ, ดาวระยิบ, ป้ายไฟเปลี่ยนสี, รถวิ่ง, คนเดิน, BTS ผ่านเป็นระยะ
- ปุ่ม: **เล่นต่อ** (ถ้ามีเซฟ) → **เริ่มชีวิตใหม่** → **วิธีเล่น** → **เสียง**
- แสดงข้อมูลเซฟสั้น ๆ (ชื่อ/อายุ/บท)
- ปุ่มเริ่มใหม่เมื่อมีเซฟต้องเตือนว่าจะเขียนทับ

## 8. สิ่งที่แต่งเพิ่ม (fictionalized)
- ตำแหน่งตึก/วัด/ป้ายในฉากเป็น composition ศิลปะ ไม่ใช่แผนที่จริง
- เวลารถ/BTS และจำนวนประชากรบนถนนเป็นจังหวะเกม
- ป้ายโฆษณาใช้สีเปลี่ยนได้ ไม่มีข้อความแบรนด์จริง
