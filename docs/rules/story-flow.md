# กฎเนื้อเรื่อง (Story Flow & Writing)

> เกมนี้คือ "หนึ่งชีวิตคนไทย" — เรื่องต้องรู้สึกเหมือนชีวิตจริงที่ต่อเนื่อง ไม่ใช่การ์ดสุ่มที่ไม่เกี่ยวกัน

- เนื้อหาบทใหม่ต้องเข้ากับอายุ: ห้ามมี event ออฟฟิศในวัยเรียน, ห้ามมี event วัยรุ่นตอน 50

## 2. Arc (เรื่องต่อเนื่องหลายปี)
- arc = ชุด event 3–6 ตอนที่เชื่อมด้วย flag เช่น เพื่อนชวนลงทุน → ร้านไปได้/เจ๊ง → เพื่อนขอยืมเพิ่ม → ผลตอนท้าย
- โครง: **ปูเรื่อง → แรงกดดัน → จุดเปลี่ยน → ผล** และควรกินเวลาหลายเดือนถึงหลายปีในเกม
- ทุก arc ต้องมีทางจบหลายแบบตามตัวเลือก และ**ทุกทางต้องจบได้** (ไม่มี flag ค้างที่ไม่มีตอนต่อ)
- ตั้งชื่อ flag ของ arc: `<arc><Step>` แบบ camelCase เช่น `friendArc1`, `friendInvest`
- event ตอนต่อต้องเช็คทั้ง flag ตอนก่อน และ `noFlag` ของตัวเอง (กันเกิดซ้ำ)
- arc อยู่ใน `src/data/arc-events.json` แยกตามบท

## 3. ตัวละครสำคัญ (NPC)
- ชุดหลักใน `life.people`: เพื่อนสนิท (นนท์) · หัวหน้า (คุณสมชาย) · คู่รัก (มิ้นท์) · ลูก — ใช้ชื่อเดิมให้ต่อเนื่อง ห้ามเปลี่ยนชื่อกลางเรื่อง
- NPC ใหม่ที่วนกลับมา ต้องเพิ่มใน `life.people` หรือมี flag จำความสัมพันธ์
- ชื่อ NPC ใช้ชื่อเล่นไทยที่เหมาะกับยุคและภูมิภาค (เช่น ชื่อจีน-ไทยในเยาวราช ชื่อมุสลิมในชุมชนมุสลิมสงขลา) โดยไม่เหมารวม
- NPC มีความต้องการของตัวเอง ไม่ใช่มีไว้แค่ให้ผู้เล่นได้ประโยชน์

## 4. โทน
- ผสมสี่โทนให้สมดุล ประมาณ: **ดราม่าสมจริง 40% · เสียดสี 25% · อบอุ่น/ซาบซึ้ง 20% · ตลก 15%**
- เรื่องหนักต้องมีจังหวะพัก — อย่าให้ event หนักติดกันเกิน 2–3 อัน
- เสียดสีระบบ (ออฟฟิศ ราชการ ทุนนิยม) ได้ แต่ห้ามเหยียดคน (ดู [content-safety.md](content-safety.md))
- ความตาย/ความสูญเสียต้องให้เวลาผู้เล่นรู้สึก (ข้อความสั้นแต่มีน้ำหนัก ไม่ข้ามด้วย toast)

## 5. ภาษาเขียน (ภาษาไทยในเกม)
- เล่าด้วยบุรุษที่สอง "คุณ" ในเนื้อหา event; บทพูดของ NPC อยู่ใน “ ” และใช้ภาษาพูดได้
- ประโยคสั้น อ่านจบบนมือถือภายใน ~10 วินาที: `text` ≤ 220 ตัวอักษรโดยประมาณ (ยาวกว่านี้ได้เฉพาะ event หลักของบท)
- ป้ายตัวเลือก (`label`): ขึ้นต้นด้วยกริยา บอกการกระทำ ≤ 40 ตัวอักษร เช่น "ให้ยืม 20,000 พอช่วยได้"
- ภาษาถิ่น/คำแสลง: ใช้พอให้มีสีสันและต้องถูกต้อง ห้ามใช้ล้อ
- คำหยาบ: ใช้ได้ในบทพูดระดับ "กู/มึง" ระหว่างเพื่อนสนิท ห้ามคำด่าเหยียด
- ตัวเลขในข้อความใช้เลขอารบิก คั่นหลักพัน และมี ฿ เมื่อเป็นเงิน
- คำที่ต้องใช้ให้ตรงกันทั้งเกม: "เขต" (กรุงเทพฯ เท่านั้น) / "อำเภอ" (จังหวัดอื่น) / "ย่าน" (ชื่อเชิงสังคม ไม่ใช่หน่วยราชการ)
- ห้ามใส่ข้อความใด ๆ ลงในโลกพิกเซล ข้อความอยู่ใน DOM เท่านั้น (ดู [art.md](art.md))

## 6. ความต่อเนื่องของเรื่อง (Narrative Consistency) — ตรวจด้วย `__ol.narrativeAudit()`
1. **พ่อแม่:** event ที่พูดถึงพ่อแม่ต้องมี `cond`/`requires` ตรวจ `parents.alive` (ยกเว้นวัยเด็กที่พ่อแม่ยังอยู่แน่นอน)
   - พ่อแม่เสียแล้ว ห้ามมี event ขอเงิน/มาอยู่ด้วย/ป่วยอีก
   - "บ้านของพ่อแม่" ต้องมี `!parents.alive` + flag ใช้ครั้งเดียว
2. **ลูก:** ต้องมี `flags.kid` และอายุลูก (`childAgeMin/Max`) ตรงช่วง; หลานต้องมี `flags.grandchild`
3. **คู่รัก:** ต้องมี `flags.married` หรือ `rel.love` ตามบริบท; หย่าต้อง set `married=false`
4. **งาน:** ถ้า `finance.salary <= 0` ห้ามมี event ออฟฟิศ/หัวหน้า/บริษัท (ยกเว้น event หางาน)
5. **บ้าน/รถ/เกษียณ:** ซ่อมบ้านต้องมี `flags.house`; ขายรถต้องสอดคล้อง `flags.car`; event เกษียณต้องมี `!flags.retired`
6. **รางวัลครั้งเดียว:** เงินก้อน/มรดก/ขายทรัพย์ ต้องมี flag กันรับซ้ำ
7. **ภูมิหลัง:** ครอบครัวแตกแยกมี `rel.family` ต่ำ — event ที่สมมติความอบอุ่นมากต้องรอให้ความสัมพันธ์ฟื้น (เช่น `minRel.family >= 30`)
8. **สถานที่:** event เฉพาะเขต/จังหวัดต้องมี `requires.district` หรือเงื่อนไขจังหวัด และเนื้อหาต้องตรงกับ research card
9. **เวลา:** event ฤดูกาลต้องตรงเดือน (`month` 0–11) และตรงปฏิทินไทย (สงกรานต์ = เม.ย., ลอยกระทง = พ.ย. ตามจันทรคติ TODO(research) ถ้าจะผูกวันจริง)

## 7. ความฝัน ภูมิหลัง และตอนจบ
- ความฝันต้องถูกพูดถึงซ้ำระหว่างชีวิต (event เตือนใจ โอกาส ทางแยก) ไม่ใช่โผล่แค่ตอนเริ่มและตอนจบ
- ภูมิหลังต้องมีผลต่อ event และความรู้สึก ไม่ใช่แค่เงินเริ่มต้น
- หน้าสรุปชีวิตต้องอ้างถึงเหตุการณ์จริงที่ผู้เล่นเลือก (จาก `life.log`, milestones) อย่างน้อย 3 เรื่อง
