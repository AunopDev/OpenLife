# กฎแอนิเมชัน (Objects, Characters, World, UI)

> โลกต้อง "มีชีวิต" แต่ไม่วุ่นวายจนอ่านเกมไม่ออก และต้องลื่นบนมือถือ
> ท่าตัวละครอยู่ใน [characters.md §4](characters.md) · เสียงที่ผูกกับแอนิเมชันอยู่ใน [audio.md](audio.md)

---

## 1. หลักการ
1. **ทุกสิ่งที่ในชีวิตจริงขยับ ควรขยับ** — น้ำ ใบไม้ ควัน ไอน้ำ ธง ผ้า ไฟป้าย พัดลม รถ สัตว์ คน
2. **ขยับน้อยแต่ต่อเนื่อง** ดีกว่าขยับมากแต่กระตุก — ระยะขยับทั่วไป 1–2 px
3. **ไม่ขยับพร้อมกันทั้งเมือง:** ทุกวัตถุมี phase offset ของตัวเอง (seed จากตำแหน่ง/ id) — ห้ามต้นไม้ทุกต้นโยกจังหวะเดียวกัน
4. **แอนิเมชันต้องสื่อสถานะ:** ร้านเปิด/ปิด ไฟเปิด/ดับ ฝนตก ลมแรง กลางวัน/กลางคืน
5. **ผลลัพธ์แน่นอน:** ใช้นาฬิกากลาง (`anim` วินาที) + seed — ห้ามสุ่มด้วย `Math.random` ระหว่างวาด (ภาพจะกะพริบ/ไม่ซ้ำเดิม)
6. **เคารพ `prefers-reduced-motion`:** ลดหรือหยุดแอนิเมชันตกแต่ง (คลื่น ใบไม้ ควัน parallax shake) แต่คงแอนิเมชันที่สื่อข้อมูล (ไฟเลี้ยว ตัวละครเดิน)

## 3. แคตตาล็อกแอนิเมชันของโลก
### 3.1 ธรรมชาติ
- ต้นไม้: ทรงพุ่มโยก (เลื่อนกลุ่มใบด้านบน 1 px) ใบไม้ร่วงประปราย (ต้นจามจุรี/ลีลาวดี) — ลมแรงเพิ่มแรงโยก
- หญ้า/กอหญ้า: ขยับเมื่อผู้เล่นเดินผ่าน **[อนาคต]**
- น้ำ: ระลอก ประกายแดด กลางคืนมีเงาสะท้อนไฟ ผักตบลอยช้า
- ทะเล: ฟองคลื่นเข้า-ออกหาด เรือโยก ทุ่นโยก
- ท้องฟ้า (เฉพาะฉากที่เห็น เช่น เมนู): เมฆลอย ดาว
- นก: ฝูงบินผ่าน, พิราบจิกพื้น/บินหนีเมื่อผู้เล่นเข้าใกล้ (รัศมี ~2 tile)
- แมลง: ผีเสื้อกลางวัน (สวน) แมลงเม่ารอบเสาไฟกลางคืน หิ่งห้อย (ชนบท ริมน้ำ)

### 3.2 เมือง
- ไฟจราจร: วงจรเขียว-เหลือง-แดง (ย่อเวลาจริงลง) และรถหยุด/ไปตามไฟ **[อนาคต]**
- ป้ายไฟ/นีออน: เปิดตอนพลบค่ำ บางดวงกะพริบ
- ประตูม้วนตึกแถว: เปิดช่วงเช้า ปิดช่วงดึก (ตามประเภทร้าน; ร้านสะดวกซื้อเปิด 24 ชม.)
- ไฟหน้าต่าง: ทยอยเปิดหลังพลบค่ำ ทยอยดับหลังเที่ยงคืน (seeded ต่อหน้าต่าง) บางห้องมีแสงทีวีกะพริบ
- เสาไฟถนน: ติดตอนพลบค่ำ อาจกะพริบตอนเปิด 1–2 ครั้ง
- แผงลอย: ไอน้ำหม้อก๋วยเตี๋ยว ควันเตาย่าง ร่มโยกตามลม
- คอมแอร์: พัดลมหมุน + หยดน้ำ (บางเครื่อง)
- ราวตากผ้า ธง ผ้าใบกันสาด: ปลิวตามลม
- ประตู: เปิดเมื่อผู้เล่นเข้า/ออกอาคาร (2–3 เฟรม)

### 3.3 ยานพาหนะ
- ล้อหมุน (2–4 เฟรม) ขณะเคลื่อนที่; ตัวรถสั่น 1 px เมื่อจอดติดเครื่อง (มอเตอร์ไซค์ ตุ๊กตุ๊ก)
- ไฟเบรกสว่างเมื่อชะลอ ไฟเลี้ยวก่อนเลี้ยว ไฟหน้าตอนกลางคืน (ลำแสงแบบ additive)
- ควันท่อเมื่อออกตัว (มอเตอร์ไซค์ รถเมล์ ตุ๊กตุ๊ก)
- รถเมล์/สองแถว: จอดป้าย เปิดประตู คนขึ้นลง **[อนาคต]**
- รถจอดนิ่งไม่ต้องเคลื่อนไหว

### 3.4 สภาพอากาศและเวลา
- ฝน: เส้นฝนเฉียง 2–3 px (2 ชั้นความเร็ว) + กระเซ็นบนพื้น + แอ่งน้ำมีวงกระเพื่อม + พื้นเปียกสะท้อนแสง + คนกางร่ม/วิ่งหลบ
- ลมแรง: ต้นไม้/ธง/ร่มโยกแรงขึ้น ใบไม้ปลิว
- ร้อนจัด: ไอแดดระยิบบนถนนช่วงบ่าย (เบามาก)
- เวลา: เปลี่ยนโทนแสง 4 ช่วง (รุ่งเช้า กลางวัน พลบค่ำ กลางคืน) แบบไล่ค่อยเป็นค่อยไป ไม่ตัดฉับ

### 3.5 การโต้ตอบและ feedback ในโลก
- จุดที่โต้ตอบได้: แสงหรือลูกศรเต้นเบา ๆ (รอบ 1–1.5 วิ) เมื่อผู้เล่นอยู่ใกล้ — ไม่กะพริบตลอดเวลา
- เป้าหมายการแตะเดิน: marker ยุบ-ขยาย 2–3 รอบแล้วหาย
- รายได้/ค่าใช้จ่าย: ตัวเลขลอยขึ้นและจางใน DOM (ไม่ใช่ข้อความในโลกพิกเซล)
- ชน/เฉี่ยว: screen shake สั้น ≤ 300 ms เฉพาะเหตุการณ์แรง

## 4. แอนิเมชัน UI (DOM)
- เปิด modal: เลื่อนขึ้น + จางเข้า 200 ms · ปิด 150 ms
- แถบสถานะเปลี่ยนค่า: ไล่ความยาว 300–500 ms + กะพริบสีครั้งเดียว (ขึ้น = เขียว ลง = แดง + ลูกศร)
- ตัวเลขเงิน: นับขึ้น/ลง ≤ 600 ms
- toast: เลื่อนเข้า 150 ms ค้าง 2.5–4 วิ
- ห้าม animation วนไม่รู้จบบนองค์ประกอบ UI ที่ไม่ต้องการความสนใจ

## 5. การทำแอนิเมชันใน sprite
- sprite sheet: แถว = ท่า/ทิศ, คอลัมน์ = เฟรม; metadata ระบุ duration ต่อเฟรม และ tag ชื่อท่า ([assets.md §2](assets.md))
- เฟรมแรกของทุกท่า = ท่าพักที่ต่อจาก idle ได้ (ไม่กระตุกตอนเปลี่ยนท่า)
- ท่าที่วนต้องต่อเนื่อง (เฟรมสุดท้าย → เฟรมแรกลื่น)
- เปลี่ยนท่าระหว่างกลางรอบได้ แต่ทิศต้องเปลี่ยนทันที
- ใช้หลัก squash/stretch เบา ๆ (1 px) กับของนิ่ม (ผ้า ใบไม้ สัตว์) ไม่ใช้กับอาคาร

## 6. ประสิทธิภาพ
- วาดเฉพาะแอนิเมชันที่อยู่ในกล้อง (+ ขอบเผื่อ 1 tile)
- ของที่ขยับต้องแยกจาก static layer — ห้าม rebuild static layer ทุกเฟรม
- การเปลี่ยนสถานะช้า ๆ (ประตูม้วนเปิด/ปิด ไฟหน้าต่าง) อัปเดตเป็นจังหวะ (เช่น ทุก 1 นาทีเกม) ไม่ใช่ทุกเฟรม
- จำกัดจำนวน: อนุภาค ≤ 200 บนมือถือ · NPC ≤ 30 · รถ ≤ 15 — ลดอัตโนมัติถ้า fps < 45 ต่อเนื่อง
- หยุดแอนิเมชันเมื่อเกม pause หรือแท็บถูกซ่อน
