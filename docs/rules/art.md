# กฎงานภาพ (Pixel Art 32px)

> **มาตรฐานใหม่ (เจ้าของกำหนด):** 1 tile = **32×32 art px** (เดิม 16) · ตัวละคร**สัดส่วนสมจริง** · ภาพผสม **sprite PNG + วาดด้วยโค้ด** · ใช้รูปถ่ายสถานที่/วัตถุจริงเป็นภาพอ้างอิงได้
> ไฟล์ที่เกี่ยวข้อง: [characters.md](characters.md) (ตัวละคร) · [animation.md](animation.md) (การเคลื่อนไหว) · [audio.md](audio.md) (เสียง) · [assets.md](assets.md) (ไฟล์ภาพ/เสียง ภาพอ้างอิง ลิขสิทธิ์)
> รายละเอียดวัฒนธรรมของภาพถนนไทย: [`docs/research/city-streetscape-art.md`](../research/city-streetscape-art.md)

## 1. สถานะการย้ายจาก 16px → 32px
โค้ดปัจจุบันยังเป็น 16px (`ART = 16`, `W2A = 4`) — การย้ายทำเป็นเฟส **ห้ามเปลี่ยนค่าคงที่ทั้งเกมทีเดียว**
| เฟส | งาน | เสร็จเมื่อ |
|---|---|---|
| 0 | กฎ (ไฟล์นี้) | ✅ |
| 1 | เอนจิน: `ART = 32`, `W2A = TILE/ART = 2`, ตารางซูมจำนวนเต็ม (§3), static layer แบบ chunk (§4); ภาพเก่า 16px ขยาย ×2 แบบ nearest เป็นเลเยอร์ชั่วคราว | เกมเล่นได้เหมือนเดิม audit ผ่าน |
| 2 | ตัวละครผู้เล่น + NPC + สัตว์ เป็น sprite 32px ตาม [characters.md](characters.md) | ผู้เล่น/NPC ทุกตัวไม่ใช่ภาพขยาย |
| 3 | แผนที่เมือง: kit อาคาร/ตึกแถว/props + พื้น/ถนน/น้ำ 32px | ไม่มีภาพขยายในแผนที่เมือง |
| 4 | ฉากภายใน (บ้าน ออฟฟิศ ร้าน สถานี) | |
| 5 | แผนที่เฉพาะเขต (บางขุนเทียน) + เมนูหลัก | ลบโค้ดภาพ 16px ทั้งหมด |
- ระหว่างย้าย: ห้ามผสมภาพ 16px ขยายกับภาพ 32px **ในวัตถุชิ้นเดียวกัน**; ในฉากเดียวกันผสมได้ชั่วคราวเท่านั้น และต้องจดเป็นหนี้งานไว้ใน GDD
- ทุกเฟสต้องผ่าน Definition of Done และเซฟเก่าต้องโหลดได้ (พิกัด world ใช้ `TILE = 64` เหมือนเดิม จึงไม่กระทบเซฟ)

> **สถานะล่าสุด:** เฟส 0 ✅ · **เฟส 1 ✅ (พื้นฐาน)** — `src/render/scale.ts` (world↔art↔screen + test) · `OUT_SCALE = 2` (16px legacy → 32px output, nearest) · `screenToWorld()`/labels ใช้ `PIX16` · ตารางซูมใหม่: แผนที่ 1x · ถนน 3x · ภายใน 2x (ปรับได้ 2–4x / 1–3x) · เกม/เซฟ/พิกัด world ไม่เปลี่ยน · audit + e2e ผ่าน
> **ยังไม่ทำ (ตั้งใจเลื่อน):** static layer แบบ chunk (§4) — เลเยอร์ปัจจุบันเล็ก (640×448 art px) ยังไม่จำเป็น; จะทำเมื่อแผนที่ใหญ่ขึ้นหรือเริ่มมีภาพ 32px จริงในเฟส 2
> **หนี้งานที่ต้องจดใน GDD:** ระหว่างเฟส 2–5 แผนที่/ตัวละครยังเป็นภาพ 16px ที่ถูกขยาย ×2 (ไม่ใช่ภาพ 32px ของจริง)

## 2. สเกลโลก (World Scale) — ใช้ร่วมกันทุกภาพ
> เป้าหมาย: คน รถ ของใช้ ดู "ขนาดถูกกัน" แบบสมจริง ส่วนอาคารและระยะทางย่อได้เพื่อให้แผนที่เล่นสนุก
- **พื้นราบ:** 1 tile ≈ 1 เมตร สำหรับ คน รถ ของบนพื้น ถนน ทางเท้า
- **แนวตั้ง (ความสูงบนจอ):** ใช้สเกลเดียวกับตัวละคร — ประตู 2.1 ม. ≈ 60–64 px
- **อาคาร:** ความกว้างหน้าอาคารใกล้ของจริง (ตึกแถว 1 คูหา ≈ 4 tile) แต่ความลึกย่อได้ 40–60%; ผนังด้านหน้าแสดงสูงสุด **2 ชั้นเต็มสเกล** ชั้นที่สูงกว่านั้นแสดงผ่านขนาดหลังคา/เงา ไม่เพิ่มความสูงผนัง (กฎลัดมาตรฐานของเกมมุมบน)

## 3. การเรนเดอร์และการซูม
- วาดลง buffer ที่ art resolution แล้วขยายด้วย **nearest-neighbour เท่านั้น**: ห้ามเปิด `imageSmoothingEnabled`, canvas ต้องมี `image-rendering: pixelated`
- **ขยายเป็นจำนวนเต็มเท่านั้น** (×1, ×2, ×3) — ห้าม ×2.5 ห้ามย่อภาพ 32px ลงเพื่อดูภาพรวม (จะเกิดพิกเซลแตก)
- เป้าการมองเห็น (ปรับ PIX ให้ใกล้ที่สุดแบบจำนวนเต็ม):
  | โหมด | มองเห็นประมาณ | หมายเหตุ |
  |---|---|---|
  | เดินในเมือง (มือถือ portrait) | กว้าง 11–14 tile | |
  | เดินในเมือง (มือถือ landscape / เดสก์ท็อป) | กว้าง 20–24 tile | เดสก์ท็อป 1440 px ≈ ×2 |
  | ภายในอาคาร | ทั้งห้องหรือเกือบทั้งห้อง | |
  | ภาพรวมเมือง | ทั้งแผนที่ | ใช้ **เลเยอร์แผนที่แยก** แบบเรียบ 8 px/tile (ไอคอน+สี) ไม่ย่อภาพ 32px |
- **ห้ามใช้ `PIX` แปลงพิกัด** — `PIX` ใช้ขยายขึ้นจอเท่านั้น; แปลง art ↔ world ด้วย `W2A`
- **พิกัด art ต้องเป็นจำนวนเต็มเสมอ** (`px()`/`Math.round()`) รวมถึงตำแหน่งกล้อง (ปัดกล้องเป็น art px ก่อนวาด เพื่อไม่ให้ภาพสั่นตอนเลื่อน)
- รองรับ `devicePixelRatio`: canvas backing ใหญ่ตาม DPR แต่ยังขยายแบบจำนวนเต็มต่อ art px

## 4. เลเยอร์และหน่วยความจำ
ลำดับการวาด (ล่าง → บน):
1. **พื้น** (static): ดิน หญ้า คอนกรีต ถนน ทางเท้า น้ำนิ่ง
2. **ของบนพื้นแบน** (static): เส้นถนน ฝาท่อ คราบ ร่องรอย เงานิ่ง
3. **วัตถุตั้งพื้น** (static ถ้าไม่ขยับ): อาคาร ต้นไม้ props — เรียงตาม y ของฐาน
4. **ของที่ขยับ** (ทุกเฟรม): ผู้เล่น NPC รถ สัตว์ — เรียง y ร่วมกับวัตถุที่บังได้ (ต้นไม้ใหญ่ เสา ป้าย)
5. **ส่วนที่ต้องอยู่เหนือตัวละคร**: ยอดต้นไม้/หลังคา/สายไฟที่ตัวละครเดินลอดได้ (ทำเป็นเลเยอร์ "เหนือหัว" แยก)
6. **เอฟเฟกต์**: ควัน ไอน้ำ ฝน ใบไม้ร่วง
7. **แสง**: night tint → เลเยอร์เรืองแสงกลางคืน (`src/render/night.ts`) → แสง additive (`'lighter'`)
8. **DOM**: ป้ายชื่อสถานที่ HUD
- ฉากนิ่งวาด **ครั้งเดียว** ลง static layer; ทุกเฟรมวาดเฉพาะของที่ขยับและอยู่ในกล้อง
- **ขนาด canvas ต่อเลเยอร์ไม่เกิน 8 ล้านพิกเซล** (มือถือ iOS จำกัดราว 16.7 ล้าน) — แผนที่ใหญ่กว่านั้นแบ่งเป็น chunk 1024×1024 และสร้างเฉพาะ chunk ใกล้กล้อง
- กลางวัน/กลางคืนแยก: เลเยอร์กลางวันหน้าต่างเป็นกระจกมืด; ไฟหน้าต่าง/ป้าย/หน้าร้านอยู่ในเลเยอร์กลางคืนโปร่งใสที่วางทับหลัง tint

## 5. สไตล์พิกเซลที่ 32px (กฎความสวย)
### 5.1 แสงและเงา
- **แสงมาจากซ้ายบน** ทุกภาพ — ด้านขวา/ล่างของวัตถุมืดกว่า
- เงาบนพื้นตกไป **ขวา-ล่าง** เป็นวงรีหรือรูปทรงตามวัตถุ ใช้สีเงาอมน้ำเงิน-ม่วงโปร่ง ~30–40% ไม่ใช่ดำล้วน
- ห้าม pillow shading (ไล่มืดรอบขอบทุกด้านเท่ากัน)

### 5.2 เส้นขอบ (outline)
- ใช้ **selective outline**: ขอบนอกเป็นสีเข้มของวัตถุนั้นเอง (ไม่ใช่ดำ #000) ด้านรับแสงขอบอ่อนลงหรือไม่มี
- ตัวละครและวัตถุที่ต้องเด่นจากพื้นมีขอบนอก 1px เสมอ; พื้น/ผนังไม่ต้องมีขอบ
- เส้นภายในใช้สีที่อ่อนกว่าขอบนอก

### 5.3 สีและการไล่เฉด
- แต่ละวัสดุมี ramp 3–5 เฉด และ **hue shift**: เงาอมฟ้า/ม่วง แสงอมเหลือง/ส้ม (ไม่ใช่แค่ทำให้มืด/สว่าง)
- sprite หนึ่งชิ้นใช้ไม่เกิน ~16–24 สี; ใช้สีจาก **master palette** เท่านั้น (`src/render/palette.ts` ↔ `assets-src/palette/openlife.gpl`) — สีใหม่ต้องเพิ่มใน palette ก่อน
- คอนทราสต์: วัตถุที่โต้ตอบได้ต้องเด่นกว่าฉากหลัง (value ต่างชัด)

### 5.4 เส้นและรูปทรง
- เส้นเอียงใช้จังหวะขั้นบันไดสม่ำเสมอ (1:1, 1:2, 2:1, 1:3) — ห้ามมี "jaggies" ขั้นไม่สม่ำเสมอ
- ห้ามมีพิกเซลกำพร้า (orphan pixel) ที่ไม่ได้สื่ออะไร
- Anti-aliasing ด้วยมือได้ **ภายใน** sprite เท่านั้น; ขอบที่ติดพื้นโปร่งใสต้องคม (ไม่มีขอบฟุ้ง) เพื่อวางบนพื้นไหนก็ได้

### 5.5 พื้นผิว (texture)
- ใช้กลุ่มพิกเซล (cluster) 2–6 px สื่อพื้นผิว ไม่ใช่จุดสุ่มกระจาย (salt & pepper)
- dithering ใช้น้อย เฉพาะ gradient ใหญ่หรือพื้นผิวหยาบ (ยางมะตอย กรวด)
- พื้นที่ใหญ่ต้องมี variation (ลาย tile 2–4 แบบสลับแบบ seeded) ไม่ให้เห็นลายซ้ำเป็นตาราง

### 5.6 วิธีวาดวัสดุ (ที่ 32px)
| วัสดุ | วิธีวาด |
|---|---|
| คอนกรีต | แผ่นละ 1–2 tile มีรอยต่อ 1px, คราบน้ำไหลแนวตั้งใต้หน้าต่าง/ท่อ, มุมบิ่น |
| ยางมะตอย | cluster 2 เฉด + รอยปะสี่เหลี่ยมคนละเฉด + คราบน้ำมันกลางช่องจราจร |
| เส้นจราจร | กว้าง 2 px, เส้นประ 16 px เว้น 16 px, ซีดเป็นช่วง ๆ |
| ทางเท้า | กระเบื้อง 8×8 หรือ 16×16 มีร่องยาแนว, กระเบื้องแตก/ยุบบางแผ่น, ขอบคันหินมีสีตามกฎ (ขาว-แดง/ขาว-เหลือง) |
| หญ้า | 3 เฉด + กอหญ้า 3–5 px + ดอกไม้เล็กประปราย |
| ดิน/ทางดิน | 2–3 เฉด + ก้อนกรวด + รอยล้อ |
| สังกะสี | ลอน 2 px สลับ 2 เฉด + สนิมเป็นหย่อม |
| กระเบื้องหลังคา | แถวโค้ง 4–6 px สลับเหลื่อม + สันหลังคา |
| ไม้ | แผ่นกระดาน 4–6 px + ลายไม้ 1 px + ปุ่มตะปู |
| กระจก | พื้นเข้ม + ไล่เฉดแนวตั้ง + แถบสะท้อนเฉียง 2 px + กรอบอะลูมิเนียม |
| โลหะ/สแตนเลส | ไฮไลต์ 1 px คม + เงาเข้มตัดกัน |
| น้ำคลอง | เขียวขุ่น-น้ำตาล 2–3 เฉด + ผักตบ + ระลอก (เคลื่อนไหว) |
| น้ำทะเล | ไล่เฉดตามความลึก + ฟองคลื่นริมหาด (เคลื่อนไหว) |
| ใบไม้ | ก้อนใบ 4–8 px 3 เฉด + ไฮไลต์ด้านซ้ายบน + ช่องว่างให้เห็นกิ่ง |

## 6. อาคาร: ใช้ระบบ "kit" ประกอบด้วยโค้ด
- อาคารที่ซ้ำบ่อย (ตึกแถว บ้าน อพาร์ตเมนต์) สร้างจาก **ชิ้นส่วน 32px**: ผนัง ประตูม้วน (เปิด/ปิด/ครึ่ง) หน้าร้าน หน้าต่าง (เหล็กดัด/บานเกล็ด/กระจก) แอร์ ป้ายร้าน กันสาด ราวระเบียง หลังคา ถังน้ำ จานดาวเทียม ราวตากผ้า
- โค้ดประกอบ kit ด้วย seeded RNG ให้แต่ละคูหาไม่เหมือนกัน (สี ป้าย ของบนดาดฟ้า ประตูเปิด/ปิด) และเปลี่ยนสถานะตามเวลา (ประตูม้วนเปิดเช้า ปิดดึก)
- อาคารสำคัญ/landmark (วัด ห้าง โรงพยาบาล สถานี) วาดเป็น sprite เฉพาะชิ้นได้
- ทุกอาคารต้อง **อ่านออกว่าเป็นอะไรจากรูปทรงและของประกอบ** ไม่ใช่จากสี; ประตูที่เข้าได้ต้องเห็นชัด (มีพรม/ไฟ/ป้าย)

## 7. ภาพต้องเป็นไทยจริง
**ต้องมี (ตามบริบทพื้นที่):** ตึกแถว (ดาดฟ้าแบน ถังน้ำ คอมแอร์ เหล็กดัด ประตูม้วน ป้ายร้าน) · เสาไฟฟ้าคอนกรีต + สายไฟหย่อน · ขอบทาง ขาว-แดง ใกล้แยก ขาว-เหลือง หน้าป้ายรถเมล์ · ศาลพระภูมิ · มอเตอร์ไซค์จอด · วินเสื้อกั๊กส้ม · รถเข็นร่มสี · โต๊ะ/เก้าอี้พลาสติก · ตู้น้ำหยอดเหรียญ · วัดไทยหลังคาซ้อน + ช่อฟ้า (ล้านนาในภาคเหนือ ศาลเจ้าจีนในย่านจีน มัสยิดในชุมชนมุสลิม) · ต้นไม้ตามภาค (จามจุรี ลีลาวดี มะม่วง กล้วย มะพร้าวภาคใต้)
**ห้ามวาด:**
- ปล่องไฟ หิมะ ต้นสน บ้านอิฐแดงแบบอังกฤษ หัวดับเพลิงแบบอเมริกัน (ถ้าไม่มี research รองรับ)
- ย่าน CBD เป็นทุ่งหญ้ามีกระท่อม
- ศาลเจ้าจีนแทนวัดไทยในทุกจังหวัด
- โลโก้ ลายสี หรือ trade dress ของแบรนด์จริง; ตัวอักษรที่อ่านออก
- สัญลักษณ์ที่ผิด [content-safety.md §1](content-safety.md) (เช่น ซุ้มเฉลิมพระเกียรติ)
- ภาพลอกจากรูปถ่าย (trace) หรือจาก asset เกมอื่น ([assets.md §4](assets.md))

## 8. ห้ามมีตัวอักษรในโลกพิกเซล
- ป้ายร้านใช้ไอคอน + แท่งแทนตัวอักษร (lettering bars) ที่สื่อว่าเป็นป้ายภาษาไทย/จีน/อังกฤษด้วยรูปทรง แต่ **อ่านไม่ออก**
- ข้อความจริงทั้งหมดอยู่ใน DOM (HUD, ป้ายชื่อสถานที่ `#mapLabels`)

## 9. วิธีสร้างภาพ: sprite vs โค้ด
| ประเภท | วิธี | เหตุผล |
|---|---|---|
| ตัวละคร NPC สัตว์ | sprite PNG (เลเยอร์ + เปลี่ยนสีด้วย palette) | ต้องสวยและมีหลายเฟรม |
| ยานพาหนะ | sprite PNG | |
| landmark / อาคารพิเศษ | sprite PNG | |
| ชิ้นส่วน kit อาคาร | sprite PNG ชิ้นเล็ก + โค้ดประกอบ | สวยและหลากหลายในเวลาเดียวกัน |
| props ทั่วไป | sprite PNG หรือโค้ด | ของที่ต้องหลายสี/หลายขนาดใช้โค้ดได้ |
| พื้น ถนน น้ำ รอยต่อพื้นต่างชนิด | โค้ด (+ ลาย tile PNG ได้) | ต้องปรับตามผังแผนที่ |
| แสง ควัน ฝน เอฟเฟกต์ | โค้ด | |
- ทุก sprite ต้องมี **fallback ที่วาดด้วยโค้ด** หรือกรอบสำรอง เพื่อไม่ให้เกมพังถ้าไฟล์โหลดไม่ได้ ([assets.md §3](assets.md))
