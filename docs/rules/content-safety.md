# กฎเนื้อหาอ่อนไหว (Content Safety)

> หมวดนี้มีลำดับสูงสุดรองจากกฎหมาย — ถ้าขัดกับหมวดอื่น ให้ยึดหมวดนี้
> เป้าหมาย: เกมกล้าพูดเรื่องจริงของชีวิตคนไทย (หนี้ ความจน ความตาย ระบบที่ไม่ยุติธรรม) โดยไม่ทำร้ายใคร และไม่ทำให้เจ้าของโปรเจ็คมีความเสี่ยงทางกฎหมาย
> ระดับอายุเป้าหมาย: **13+** (ค่าเริ่มต้น — เจ้าของเปลี่ยนได้)

## 1. กฎเหล็ก (ห้ามละเมิดไม่ว่ากรณีใด)

### 1.1 สถาบันพระมหากษัตริย์ — ไม่แตะทุกรูปแบบ
- ห้ามมี event ข้อความ ตัวละคร ภาพ เสียง หรือสัญลักษณ์ที่อ้างถึงสถาบันพระมหากษัตริย์และพระบรมวงศานุวงศ์ ทั้งในแง่บวกและลบ
- ห้ามใช้ภาพพระบรมฉายาลักษณ์ ตราสัญลักษณ์ เพลงสรรเสริญพระบารมี หรือวันสำคัญที่ผูกกับสถาบันเป็นกลไกเกม
- งานภาพ: ห้ามวาดซุ้ม/ป้ายเฉลิมพระเกียรติ แม้จะเป็นภาพที่เห็นได้ทั่วไปตามถนนจริง
- เหตุผล: กฎหมายอาญามาตรา 112 มีความเสี่ยงสูงและตีความกว้าง

### 1.2 การเมือง — ใช้ของสมมติเท่านั้น
- พรรค นักการเมือง การเลือกตั้ง การชุมนุม และรัฐประหารในเกม ต้องเป็นชื่อและเหตุการณ์สมมติ **ห้ามเอ่ยชื่อ หรือทำให้จำได้ว่าเป็นบุคคล/พรรคจริง**
- ใส่ผลกระทบเชิงนโยบายได้ (ค่าแรงขั้นต่ำขึ้น ภาษีเปลี่ยน โครงการแจกเงิน น้ำท่วม) โดยไม่ชี้ว่าฝ่ายไหนถูกหรือผิด
- ห้ามมีตัวเลือกที่ทำให้อุดมการณ์ใดเป็นคำตอบที่ "ถูก" (ให้รางวัลมากกว่าเสมอ)

### 1.3 เด็กและเยาวชน
- ห้ามมีเนื้อหาทางเพศใด ๆ ที่เกี่ยวกับตัวละครอายุต่ำกว่า 18 ปี
- ความรักช่วงมัธยมเป็นได้แค่ "แฟนแรก" แบบไร้เดียงสา (จับมือ ดูหนัง เขินอาย)
- การถูกทำร้าย/กลั่นแกล้งในวัยเด็กเล่าได้ แต่ห้ามบรรยายรายละเอียด และต้องมีทางขอความช่วยเหลือ

### 1.4 ห้ามเป็นคู่มือทำผิดจริง
- พูดถึงอาชญากรรม ยาเสพติด การพนัน การโกง และแชร์ลูกโซ่ได้ แต่ **ห้ามมีวิธีทำที่นำไปใช้ได้จริง** (สูตร ขั้นตอน สคริปต์หลอกลวงที่ใช้ได้จริง วิธีหลบตำรวจ)
- event แนวมิจฉาชีพต้องสอนผู้เล่นให้ "จับสังเกต" ได้ ไม่ใช่สอนวิธีหลอกคนอื่น

### 1.5 ไม่มีกลไกพนันด้วยเงินจริง
- ห้ามมี loot box, gacha, การซื้อของด้วยเงินจริงแบบสุ่ม หรือระบบที่เลียนแบบการพนันด้วยเงินจริง
- หวย/บ่อน/พนันบอลในเนื้อเรื่องมีได้ (เป็นส่วนหนึ่งของสังคมจริง) แต่โอกาสได้ต้องสมจริง และระยะยาวต้องขาดทุน

## 2. หัวข้อที่ทำได้ แต่มีเงื่อนไข

### 2.1 อบายมุข (เหล้า บุหรี่ การพนัน ยาเสพติด)
- มีได้ แต่ต้องมี **ผลเสียที่เห็นชัดและสะสม** (สุขภาพ เงิน ความสัมพันธ์ งาน คดี) — ห้ามทำให้ดูเท่ หรือเป็นทางลัดที่คุ้ม
- ผลบวกระยะสั้น (ใจ +, สังคม +) ต้องเล็กกว่าผลเสียระยะยาวเสมอ
- สถานะทางกฎหมายเปลี่ยนบ่อย (เช่น กัญชา กระท่อม บุหรี่ไฟฟ้า) → **ต้องรีเสิร์ชกฎหมายปัจจุบันก่อนเขียนทุกครั้ง** และระบุปีที่อ้างอิงไว้ใน card

### 2.2 ศาสนาและความเชื่อ
- พุทธ อิสลาม คริสต์ ความเชื่อจีน ผี/ศาลพระภูมิ ใส่ได้ตามพื้นที่จริง (เช่น สงขลามีชุมชนมุสลิม เยาวราชมีศาลเจ้าจีน)
- แสดงด้วยความเคารพ: ห้ามล้อเลียนศาสดา พิธีกรรม สิ่งศักดิ์สิทธิ์ นักบวช
- ห้ามให้ศาสนาใดเป็นตัวเลือกที่ "ถูกต้อง" หรือได้รางวัลเกมมากกว่า
- พระ/นักบวชที่ทำผิดเป็นเนื้อเรื่องได้เฉพาะในระดับ "ข่าว" ทั่วไป ไม่เจาะจงวัดหรือบุคคลจริง
- อาหาร/กิจกรรมต้องเคารพข้อห้ามทางศาสนาของตัวละคร (เช่น ไม่เสนอหมูให้ตัวละครมุสลิมเป็นตัวเลือกปกติ) **[อนาคต: ศาสนาของตัวละคร]**

### 2.3 ความตาย ความเจ็บป่วย สุขภาพจิต
- ความตายเป็นแก่นของเกม (Design Pillar 4) — เล่าอย่างมีศักดิ์ศรี ไม่ใช้เป็นมุกตลก
- ซึมเศร้า/หมดไฟ: แสดงอาการและทางออกที่สมจริง (พบแพทย์ คุยกับคนใกล้ชิด พัก) ไม่ทำให้เป็นจุดอ่อนทางนิสัย
- **การฆ่าตัวตาย / ทำร้ายตัวเอง:** ห้ามเป็นตัวเลือกของผู้เล่น ห้ามบรรยายวิธี; ถ้าเนื้อเรื่องจำเป็นต้องพูดถึง ให้แสดงข้อความช่วยเหลือ "สายด่วนสุขภาพจิต 1323" (TODO(research): ตรวจหมายเลขกับกรมสุขภาพจิตก่อนใช้จริง)
- ความรุนแรงในครอบครัว: มีได้ในระดับเนื้อเรื่อง ต้องมีทางขอความช่วยเหลือ (เช่น ศูนย์ช่วยเหลือสังคม 1300 — TODO(research) ตรวจหมายเลข) และผู้กระทำต้องได้รับผลที่ตามมา

### 2.4 ความรุนแรงและอาชญากรรม
- ไม่บรรยายภาพรุนแรงแบบ graphic (เลือด บาดแผล ศพ)
- ผู้เล่นเลือกทำผิดได้ ผลที่ตามมาให้ทำตามระบบ "ผลกรรม" ใน [game-design.md §5](game-design.md)

### 2.5 เพศ ความรัก ครอบครัว
- ระบบแต่งตัว/อาชีพ/ความสัมพันธ์ **ไม่ล็อกตามเพศ**
- ไทยรับรองสมรสเท่าเทียมแล้ว → event ความรัก/แต่งงานต้องเขียนให้ใช้ได้กับคู่ทุกเพศ (ใช้คำว่า "คู่รัก/แฟน" แทน "สามี/ภรรยา" เมื่อไม่รู้เพศ) TODO(research): ใส่อ้างอิงวันมีผลบังคับใช้ใน card
- ไม่มีเนื้อหาทางเพศแบบโจ่งแจ้ง (เฟดภาพ/ตัดฉากแทน)
- ห้ามเหมารวมบทบาทตามเพศ (เช่น งานบ้านเป็นของผู้หญิงเท่านั้น) — ถ้ามีตัวละครคิดแบบนั้น ให้เป็นมุมมองของตัวละคร ไม่ใช่ของเกม

### 2.6 ความเหลื่อมล้ำ ภูมิภาค ชนชั้น
- ห้ามลดทอนภูมิภาคให้เหลือภาพจำเดียว เช่น อีสาน = ชาวนา/แรงงาน, ใต้ = ความไม่สงบ, เหนือ = ชาวเขา
- ภาษาถิ่นใช้ได้ในบทพูดอย่างพอดีและถูกต้อง (ให้คนท้องถิ่นตรวจถ้าทำได้) **ห้ามใช้เป็นมุกล้อ**
- แรงงานข้ามชาติ: เป็นมนุษย์ที่มีชื่อ มีเรื่องราว ไม่ใช่ฉากหลังหรือตัวตลก
- คนพิการ: ไม่ใช้เป็นบทลงโทษ ไม่ใช้เป็นแรงบันดาลใจราคาถูก
- พื้นที่ความไม่สงบชายแดนใต้: ห้ามใช้เป็นจุดขายหรือ event ตื่นเต้น; ถ้าจำเป็นต้องพูดถึงให้รีเสิร์ชลึก และถามเจ้าของก่อน

## 3. บุคคล แบรนด์ สถานที่จริง
- **ห้ามใช้บุคคลจริงที่ยังมีชีวิต** (ดารา นักการเมือง นักธุรกิจ อินฟลูเอนเซอร์) — ใช้ตัวละครสมมติ
- แบรนด์/บริษัท/ร้าน: ใช้ชื่อสมมติ หรือคำทั่วไป ("ร้านสะดวกซื้อ", "ห้างใหญ่") ห้ามใช้โลโก้ ลายสี หรือ trade dress ที่จำได้
- สถานที่สาธารณะจริง (ถนน เขต ตลาด landmark) ใช้ได้เมื่อมี research รองรับ แต่ **ห้ามพาดพิงธุรกิจจริงในทางเสียหาย** (เช่น "โรงพยาบาล ___ รักษาคนตาย")
- โศกนาฏกรรมจริง (สึนามิ 2547, น้ำท่วม 2554, โควิด) ใช้เป็นบริบทได้ แต่ต้องรีเสิร์ช ห้ามใช้เป็นมุก และห้ามบิดเบือนข้อเท็จจริง

## 4. เงินและการลงทุน
- ระบบการเงินในเกมเป็นแบบจำลองที่ย่อแล้ว ไม่ใช่คำแนะนำทางการเงิน — ถ้ามีหน้าที่สอนเรื่องการเงิน ให้มีข้อความกำกับ
- ห้ามแนะนำสินทรัพย์จริง (หุ้นตัวไหน คริปโตเหรียญไหน) ใช้ชื่อสมมติแทน
- event แชร์ลูกโซ่/หลอกลงทุนต้องจบแบบสมจริง (ส่วนใหญ่เสียเงิน)

## 5. Checklist ก่อนส่งเนื้อหา
- [ ] ไม่มีสถาบันฯ / ไม่มีบุคคล พรรค หรือแบรนด์จริง
- [ ] อบายมุขทุกอันมีผลเสียสะสมที่ชัดเจน
- [ ] ศาสนาและภูมิภาคถูกนำเสนออย่างเคารพ ไม่เหมารวม
- [ ] ไม่มีวิธีทำผิดที่นำไปใช้ได้จริง
- [ ] เรื่องหนัก (ตาย ป่วย ซึมเศร้า ความรุนแรง) มีศักดิ์ศรีและทางช่วยเหลือ
- [ ] ข้อความใช้ได้กับตัวละครทุกเพศ
- ถ้าไม่แน่ใจข้อใด → ถามเจ้าของก่อน
