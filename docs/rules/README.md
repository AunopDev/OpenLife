## ลำดับความสำคัญเมื่อกฎขัดกัน
1. กฎหมายไทย + [content-safety.md](content-safety.md)
2. [`AGENTS.md`](../../AGENTS.md) (กฎเหล็ก)
3. ไฟล์หมวดใน `docs/rules/`
4. [`docs/GDD.md`](../GDD.md) (ตัวเลข/รายละเอียด design ปัจจุบัน)
5. โค้ดที่มีอยู่

ถ้ายังตัดสินไม่ได้ → **หยุดแล้วถามเจ้าของโปรเจ็ค** อย่าเดา

## การแก้ไขกฎ
- กฎเปลี่ยนได้เฉพาะเมื่อเจ้าของโปรเจ็คสั่ง/อนุมัติ
- แก้กฎแล้วต้องแก้ทุกที่ที่อ้างถึงให้ตรงกัน (AGENTS.md ↔ rules ↔ GDD)
- เขียนเหตุผล ("ทำไม") ไว้ใต้กฎสำคัญเสมอ เพื่อให้คนต่อไปตัดสินกรณีที่กฎไม่ได้เขียนไว้ได้
- ส่วนที่ "เผื่อไว้สำหรับอนาคต" ให้ติดป้าย **[อนาคต]** — ยังไม่ต้องทำ แต่ห้ามออกแบบขัดกับมัน
