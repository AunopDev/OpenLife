> เจ้าของกำหนด: **ผสม** — สังเคราะห์ด้วย WebAudio (`src/audio/audio.ts`) + ไฟล์เสียงจริง; เจ้าของอาจแนบไฟล์เสียงมาให้เอง
> ไฟล์/ลิขสิทธิ์: [assets.md](assets.md) · แอนิเมชันที่ผูกเสียง: [animation.md](animation.md)

## 1. หลักการ
1. **เสียงบอกข้อมูล + สร้างบรรยากาศ** แต่ต้องไม่เป็นช่องทางเดียวของข้อมูลสำคัญ (คนปิดเสียงต้องเล่นได้ครบ)
2. **เสียงไทยจริงตามพื้นที่** — ตลาด มอเตอร์ไซค์ ตุ๊กตุ๊ก สองแถว นกกาเหว่า จิ้งจก ฝนบนหลังคาสังกะสี
3. **ไม่น่ารำคาญเมื่อฟังซ้ำ 6 ชั่วโมง** — เสียงที่เกิดบ่อยต้องเบา สั้น มี variation
4. **ผู้เล่นควบคุมได้:** ปิด/เปิดเสียงรวม (มีแล้ว `openlife.sound`) **[อนาคต: แยกระดับ เพลง/บรรยากาศ/เอฟเฟกต์/UI]**
5. **เคารพศาสนาและวัฒนธรรม** — ดู §7

## 2. หมวดเสียง (audio bus)
| bus | ตัวอย่าง | แหล่ง |
|---|---|---|
| `ui` | คลิก เปิด/ปิด modal เหรียญ แจ้งเตือน level up | สังเคราะห์ |
| `sfx` | ฝีเท้า ประตู ของตก มอเตอร์ไซค์สตาร์ท | ไฟล์ (+ สังเคราะห์สำหรับเสียงสั้นง่าย) |
| `voice` | เสียงอารมณ์ไม่เป็นคำ (หัวเราะ ถอนหายใจ ไอ ฮัมเพลง "อืม") | ไฟล์ |
| `ambience` | บรรยากาศย่าน/เวลา/อากาศ (loop) | ไฟล์ |
| `music` | เพลงประกอบตามบท/อารมณ์ | สังเคราะห์ (procedural) หรือไฟล์ |
- ทุก bus ผ่าน master gain เดียว; ปิดเสียงรวม = ปิด master
- **ห้ามมีเสียงพูดเป็นคำ (voice acting/TTS)** — เกมเล่าด้วยข้อความ; เสียงคนใช้แค่ "เสียงอารมณ์" สั้น ๆ

## 3. แคตตาล็อกเสียง UI (สังเคราะห์)
คลิกปุ่ม · เลือกตัวเลือก · เปิด/ปิด modal · เงินเข้า (เหรียญ) · เงินออก · stat ขึ้น · stat ลง · แจ้งเตือนสำคัญ · เลื่อนตำแหน่ง/สำเร็จ · เตือนอันตราย (หนี้ สุขภาพ) · เดินเวลา · เปลี่ยนบทชีวิต · ตอนจบ (เพลงสั้นเฉพาะ)
- ยาว ≤ 300 ms (ยกเว้นเสียงสำเร็จ/เปลี่ยนบท ≤ 2 วิ)
- โทนเดียวกันทั้งชุด (ใช้ชุด oscillator/envelope เดียวกันใน `src/audio/audio.ts`)

## 4. เสียงตัวละคร
| เหตุการณ์ | เสียง | กฎ |
|---|---|---|
| เดิน | ฝีเท้า **ตามพื้น**: คอนกรีต · กระเบื้อง · ไม้ · หญ้า · ดิน · ทราย · น้ำตื้น/แอ่งน้ำ · พรมในอาคาร | ซิงก์กับเฟรมเท้าแตะพื้น (เฟรม 1 และ 4 ของท่าเดิน) อย่างน้อย 3–5 variation ต่อพื้น สุ่มเพี้ยน pitch ±5% (seeded) |
| วิ่ง | ฝีเท้าถี่และหนักขึ้น | |
| รองเท้า | แตะ/รองเท้าผ้าใบ/ส้นสูง เสียงต่างกัน **[อนาคต]** | |
| ผ้า | เสียงเสื้อผ้าเบามากตอนเปลี่ยนท่า | |
| อารมณ์ | หัวเราะ · ถอนหายใจ · ร้องไห้เบา · ไอ · หาว · "อ๊ะ!" ตกใจ | เสียงไม่เป็นคำ, เพศ/วัยไม่จำเป็นต้องตรงเป๊ะแต่ต้องไม่ขัด (เด็กเสียงเด็ก) |
| กิจกรรม | กินข้าว (ช้อนกระทบจาน) · พิมพ์คีย์บอร์ด · ยกเวท · ผัดกระทะ · โทรศัพท์สั่น/ดัง · นอนกรนเบา | ต่อเนื่องเท่าที่ท่ายังเล่นอยู่ |
| ทักทาย | เสียงสั้นตอนคุยกับ NPC (ไม่ใช่คำพูด) | |
- ฝีเท้าของ NPC เบากว่าผู้เล่นมาก และเล่นเฉพาะ NPC ใกล้ผู้เล่น (≤ 4 tile) สูงสุด 3 ตัวพร้อมกัน

## 5. เสียงวัตถุ (objects)
| วัตถุ | เสียง | ทริกเกอร์ |
|---|---|---|
| ประตูบ้าน/ร้าน | เปิด/ปิด (ไม้ กระจก อะลูมิเนียมเลื่อน) | เข้า-ออกอาคาร |
| ประตูม้วนตึกแถว | ม้วนเหล็กดังครืด | เปิดเช้า/ปิดดึก ใกล้ผู้เล่น |
| ร้านสะดวกซื้อ | เสียงกระดิ่งประตู **แบบทั่วไป** (ห้ามเลียนเสียงจิงเกิลของแบรนด์จริง) | เข้าร้าน |
| มอเตอร์ไซค์ | สตาร์ท · เดินเบา · เร่ง · แตร | เคลื่อนที่/ผ่านใกล้ |
| ตุ๊กตุ๊ก สองแถว รถเมล์ รถเก๋ง | เครื่องยนต์ต่างกันตามชนิด · แตร · เบรก · รถเมล์เปิดประตูลม | |
| แผงลอย | ตะหลิวกระทบกระทะ · น้ำเดือด · เตาย่างฉ่า · เสียงเรียกลูกค้าแบบไม่เป็นคำ | อยู่ใกล้ |
| ตลาด | คนพูดคุยอื้ออึง (walla ที่ฟังไม่ออก) · ถุงพลาสติก · ชั่งน้ำหนัก | ambience ของตลาด |
| วัด | ระฆัง/ฆ้องเบา ๆ เป็นช่วง · ลมพัดกระดิ่งชายคา | ใกล้วัด — ดู §7 |
| ศาลเจ้าจีน | ประทัด (เฉพาะเทศกาล) · กระดิ่ง | |
| คอมแอร์ พัดลม ตู้เย็น | ฮัมเบามาก | ใกล้ (ไม่ต้องเล่นทุกเครื่อง) |
| คลอง/ทะเล | น้ำกระทบตลิ่ง · คลื่น · เรือหางยาว | ambience |
| สัตว์ | หมาเห่าไกล · แมวร้อง · ไก่ขัน (เช้าชนบท) · ตุ๊กแก/จิ้งจก (กลางคืน) · นกกาเหว่า (เช้า) · จักจั่น (บ่ายร้อน) | ตามเวลา/พื้นที่ |
| ของในบ้าน | เปิดทีวี · ก๊อกน้ำ · หม้อหุงข้าว · ไฟสวิตช์ | กิจกรรมในบ้าน |
| ของในออฟฟิศ | คีย์บอร์ด · เครื่องพิมพ์ · โทรศัพท์โต๊ะ · แอร์ | ambience ออฟฟิศ |

## 6. บรรยากาศ (ambience) และเพลง
### 6.1 ambience = ชั้นซ้อนกัน
1. **ฐานพื้นที่** ตาม archetype: `urban` (จราจรหนาแน่น แตร มอเตอร์ไซค์) · `town` (จราจรเบา นก) · `rural` (นก แมลง ลม) · `coastal` (คลื่น นกทะเล)
2. **ช่วงเวลา:** เช้า (นก ไก่ขันชนบท พระบิณฑบาตเงียบ ๆ) · กลางวัน (จักจั่น จราจร) · เย็น (ตลาดเย็น คนออกกำลัง) · กลางคืน (จิ้งจก หมาเห่าไกล จราจรลดลง)
3. **อากาศ:** ฝน (แยกเสียงบนหลังคาสังกะสี/ถนน/ใบไม้) ฟ้าร้อง ลมแรง
4. **จุดเฉพาะ (positional):** ตลาด วัด แผงลอย ท่าเรือ — ดังขึ้นเมื่อเข้าใกล้
- เปลี่ยนชั้นด้วย crossfade 2–4 วินาที ห้ามตัดฉับ
- ambience ในอาคารต่างจากข้างนอก (ลด high frequency/ระดับลงเหมือนเสียงผ่านผนัง)

### 6.2 เพลง
- procedural pad เดิมเป็นฐาน; เพลงต่างตาม **บทชีวิต** และ **อารมณ์** (ปกติ/เครียด/สุข/เศร้า) — เปลี่ยนด้วย crossfade
- เพลงต้องเบากว่า ambience เมื่ออยู่ในโลก และเด่นขึ้นในหน้า event/สรุป
- ตอนจบชีวิตมีเพลงเฉพาะ (สงบ ไม่ตื่นเต้น)
- เครื่องดนตรีไทย (ระนาด ขิม พิณ แคน) ใช้ได้ตามภูมิภาคอย่างเหมาะสม — ไม่ใช้เป็นมุก
- **[อนาคต]** เพลงไฟล์จริงต่อบท ต้องมีสิทธิ์ใช้ ([assets.md §4](assets.md))

## 7. ความอ่อนไหวทางวัฒนธรรม/ศาสนา
- ระฆังวัด สวดมนต์ เสียงอะซาน (เรียกละหมาด) **ห้ามใช้เป็นเสียงตลก ห้ามตัดต่อ/เร่ง/ทำเป็น loop สั้นซ้ำ ๆ**
- อะซาน/สวดมนต์ ถ้าจะใส่ ต้องเป็นบันทึกเสียงที่มีสิทธิ์ใช้ ตรงเวลาที่สมจริง ในพื้นที่ที่สมจริง และ **ถามเจ้าของก่อน**
- เพลงชาติ เพลงสรรเสริญพระบารมี เพลงที่ผูกกับสถาบัน: ห้ามใช้ ([content-safety.md §1](content-safety.md))
- ห้ามใช้เพลง/จิงเกิล/เสียงที่จำได้ของแบรนด์ รายการทีวี หรือเกมอื่น

## 8. การผสมเสียง (mixing) — ค่ามาตรฐาน
| ประเภท | ระดับเป้า |
|---|---|
| master | peak ≤ −1 dBFS |
| music | ~ −18 LUFS (ในโลกลดอีก ~6 dB) |
| ambience | ~ −24 LUFS |
| sfx ทั่วไป | peak −6 ถึง −10 dBFS |
| ฝีเท้า/เสียงซ้ำบ่อย | peak −18 dBFS หรือเบากว่า |
| ui | peak −12 dBFS |
- **เสียงตามตำแหน่ง:** ดังเต็มในระยะ 3 tile ลดลงจนเงียบที่ 16 tile; pan ซ้าย-ขวาตามตำแหน่งบนจอ (สูงสุด ±0.6)
- จำกัดเสียงพร้อมกัน ≤ 16 voices; เสียงชนิดเดียวกันซ้อนได้ไม่เกิน 3 (ตัดอันเก่าสุด)
- ducking: เปิด modal event → ลด ambience/sfx 6–9 dB; ข่าวสำคัญ → ลดเพลง

## 9. เทคนิค
- เริ่ม AudioContext หลัง gesture แรกของผู้ใช้ (`unlockAudio()`) — iOS บังคับ
- หยุด/พักเสียงเมื่อแท็บถูกซ่อน (`setPageVisible`) และเมื่อ pause
- โหลดไฟล์แบบ lazy ตามฉาก; เสียงที่ยังโหลดไม่เสร็จให้ข้ามไป (ไม่รอ ไม่ error)
- ไฟล์เสียงหาย/ถอดรหัสไม่ได้ → `console.warn` ครั้งเดียว แล้วใช้เสียงสังเคราะห์สำรอง หรือเงียบ
- สเปกไฟล์และงบขนาดอยู่ใน [assets.md §2.3](assets.md)
