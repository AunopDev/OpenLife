## 1. เสาหลักการออกแบบ (Design Pillars)

1. **ทุกการกระทำมีราคา** — ไม่มีการเลือกไหนที่ "ดีทุกด้าน" ผู้เล่นต้องเสียสละเสมอ
2. **เงินไม่ใช่คำตอบเดียว** — ตอนจบวัดด้วยความฝัน ครอบครัว สุขภาพ ไม่ใช่ยอดเงินในบัญชี
3. **บริบทไทยจริง** — หนี้บัตรเครดิต เครดิตบูโร ย้ายถิ่นฐาน ระบบอาวุโส ซองงานศพ เงินเดือนออกวันที่ 25
4. **ความตายคือส่วนหนึ่งของเกม** — ไม่ใช่ game over แต่คือ "บทส่งท้าย" ที่มีความหมาย

## 2. โครงเวลา (Time Structure)

### 2.1 หลักการ
แต่ละบทใช้ **หน่วยเวลาต่างกัน** กำหนดใน `data/chapters.json` เพื่อให้ผู้เล่นอินกับช่วงที่สำคัญ และไม่ต้องกดซ้ำ ๆ ในช่วงที่ชีวิตนิ่ง

### 2.2 ตารางบทชีวิต

| # | บท | อายุ | หน่วยเวลา | เทิร์น | โฟกัส |
|---|---|---|---|---|---|
| 1 | ปฐมวัย | 0–6 | 2 ปี/เทิร์น | 3 | ครอบครัว, รากฐานนิสัย, ฐานะ |
| 2 | ประถม | 7–12 | 1 ปี | 6 | เรียน, เพื่อน, ครอบครัวมีปัญหาการเงิน |
| 3 | มัธยม | 13–18 | 1 ปี | 6 | สายการเรียน, แฟนแรก, เอนทรานซ์ |
| 4 | อุดมศึกษา/อาชีวะ | 18–22 | 1 ปี | 4 | คณะ, ฝึกงาน, เพื่อนตาย, หนี้ กยศ. |
| 5 | **สร้างตัว** ⭐ | 22–27 | **1 เดือน** | 60 | งานแรก, เงินเดือน, หนี้, เลื่อนขั้น |
| 6 | ตั้งหลัก | 27–35 | 3 เดือน | 32 | แต่งงาน, ซื้อบ้าน/รถ, เปลี่ยนงาน |
| 7 | ครอบครัว | 35–45 | 6 เดือน | 20 | ลูกโต, พ่อแม่แก่, งาน/ชีวิตสมดุล |
| 8 | **วิกฤตกลางคน** ⭐ | 45–55 | **3 เดือน** | 40 | เลย์ออฟอายุ 45, หนี้, สุขภาพ |
| 9 | ปลายทาง | 55–60 | 6 เดือน | 10 | เกษียณหรือไม่, มรดก, คำตอบของชีวิต |
| 10 | ชรา | 60–ตาย | 1 ปี | 10–25 | สุขภาพ, ลูกหลาน, ความหมาย |

**รวมประมาณ 191–206 ช่วง** → ผู้เล่นเลือกก้าวเวลาเองเพื่อไม่ให้เกมยืด

### 2.3 เหตุผล
- ช่วง **22–27** คือช่วงที่ทุกการตัดสินใจเจ็บที่สุด (เงินไม่พอ หนี้เริ่ม กดดัน) → เดือนต่อเดือน
- ช่วง **45–55** คือ "วิกฤต" ที่คนไทยจำนวนมากเจอ (ถูกเลย์ออฟเพราะอายุ) → กลับมาละเอียดอีกครั้ง
- ช่วงที่ชีวิตนิ่ง (35–45) ใช้ 6 เดือน/เทิร์นเพื่อไม่ให้เกมยืด

### 2.4 บทเรียน (Tutorial) แบบฝังในเรื่อง
ไม่มี tutorial แยก — 3 เทิร์นแรกของบท "สร้างตัว" จะแนะนำระบบทีละอย่าง (สลิปเงินเดือน → กิจกรรม → event → ความสัมพันธ์)

## 3. การเริ่มต้นชีวิต

### 3.1 ลำดับสร้างตัวละคร
1. ชื่อ-นามสกุล
2. เพศ (มีผลกับ event บางอย่างเท่านั้น ไม่ผูกกับอาชีพ)
3. จังหวัดเกิด (กำหนดภายหลัง — เฟสแรกมีกรุงเทพฯ + ปริมณฑล)
4. **ภูมิหลังครอบครัว**
5. **ความฝัน** (ใช้ตัดสินตอนจบ)

### 3.2 ภูมิหลังครอบครัว — มี 2 โหมดให้เลือกตอนเริ่มเกม

| ภูมิหลัง | เงินเริ่ม | ครอบครัว | สุขภาพ | ใจ | ผลระยะยาว |
|---|---|---|---|---|---|
| **จนแต่ขยัน** | 500 | 90 | 60 | 70 | trait `แรงฮึด` (ผลงาน+) แต่โอกาสเข้าถึงการศึกษาดีน้อย |
| **กลาง ๆ** | 5,000 | 70 | 70 | 65 | สมดุล ไม่มีจุดเด่น |
| **มีเงิน แต่พ่อแม่ไม่ทำงานบ้าน** | 50,000 | 35 | 70 | 45 | trait `มีคอนเนคชัน` แต่ใจต่ำ |
| **ครอบครัวแตกแยก** | 2,000 | 20 | 65 | 30 | trait `อดทน` (ใจไม่แตกง่าย) แต่ค่าใช้จ่ายจิตใจสูง |

**โหมดเลือก:** ผู้เล่นเลือกเอง (คุมความยาก)
**โหมดสุ่ม:** สุ่มแบบถ่วงน้ำหนัก (จน/กลาง/มีเงิน/แตกแยก = 30/40/20/10) และซ่อนค่าตัวเลข ให้รู้แค่คำบรรยาย

### 3.3 ความฝัน (Life Goal) — เลือก 1

- ซื้อบ้านให้พ่อแม่
- มีครอบครัวที่อบอุ่น
- เป็นผู้จัดการก่อน 35
- มีเงินเก็บพอเกษียณ
- เป็นเจ้าของธุรกิจตัวเอง
- แค่ใช้ชีวิตให้ไม่ต้องคิดถึงเงินเดือนอีก

ความฝันมี **ตัวชี้วัด** และถูกประเมินในหน้าจอสรุปชีวิต

### 3.4 หน้าตาและทรงผม (Appearance)

หลังกรอกชื่อ/เพศ/จังหวัด ผู้เล่นจะเข้าสู่หน้าแต่งหน้าตา (ก่อนเลือกเขต/อำเภอ) โดย:
- พรีวิว pixel-art 32×32 ขยายแบบ nearest-neighbour
- แท็บ 4 กลุ่ม: **หน้า / ผม / ผิว / แต่งตัว**
- ตัวเลือก: สีผิว 6, รูปหน้า 5, ทรงผม 11 + สีผม 10, ตา 5 + สีตา 6, คิ้ว 5, จมูก 5, ปาก 5
- เพิ่ม: หนวดเครา 5, แว่น 5, หมวก 4, เครื่องประดับ 4, เสื้อ 4 ทรง + 8 สี, กระ/ไฝ
- ปุ่ม **สุ่ม** และ **ล้าง**; เปลี่ยนแล้วเห็นผลทันที
- ไม่ล็อกตัวเลือกตามเพศ
- ค่าถูกเก็บใน `life.appearance` และใช้กับ HUD portrait + ตัวละครบนแผนที่
- ตรวจด้วย `__ol.appearanceAudit()`

**เปลี่ยนหน้าตาภายหลัง**
- **กระจกที่บ้าน** (hotspot ในบ้าน): ฟรี · ความเรียบร้อย +5
- **ร้านตัดผม** (ทางเท้าเมือง): ฿300 · เปลี่ยนทรง/สีผม/หนวดเครา · ความเรียบร้อย +20
- **ร้านเสื้อผ้า** (ทางเท้าเมือง): ฿800 · เปลี่ยนเสื้อ/สี/แว่น/หมวก/เครื่องประดับ · ความเรียบร้อย +12

**ความเรียบร้อย (grooming)**
- 0–100 เริ่ม 70 ลดลง 1/เดือน
- มีผลกับ `mood` และโอกาสสัมภาษณ์งาน
- ชุดสุภาพ (เชิ้ต/เบลาส์) ให้โบนัสโอกาสหางาน +8; ชุดลำลอง −2

**วัยและรูปลักษณ์**
- อายุ 42+ เริ่มมีริ้วรอย, 55+ ชัดขึ้น, 68+ ชัดมาก
- อายุ 58+ ผมแสดงเป็นสีเทาอัตโนมัติ (ค่าสีผมที่เลือกยังอยู่ ไม่ถูกเขียนทับ)

**Wardrobe 3 ชุด**
- `life.wardrobe` เก็บเฉพาะเสื้อผ้า/แว่น/หมวก/เครื่องประดับ
- ชุด: ลำลอง / ทำงาน / ออกงาน
- ใส่หรือบันทึกทับได้ที่กระจก · ใส่ชุด +2 grooming
- `life.wardrobeActive` แสดงในหน้าชีวิต

**NPC reaction**
- หลังเปลี่ยนลุค (ตัดผม/ชุดใหม่/แต่งหน้า) ถ้า grooming ≥60
- มีคู่รัก → love +1, ใจ +1 · ไม่มี → friend +1, ใจ +1

**อาชีพสายบันเทิง**
- ตัวเลือกที่ 3 ในหน้าหางาน เมื่อ grooming ≥55 และ social ≥40
- เงินเดือน = 9,000 + grooming×140 + social×60 + creativity×90
- โอกาสผ่านขึ้นกับ grooming/social/creativity และลดลงตามอายุ 35+
- ใช้การประเมินผลแบบแยก (ไม่ไต่ตำแหน่งบริษัท) · เพดาน ฿65,000
- achievement: `looks_career`

**บัตรประชาชน**
- เปิดจากหน้าชีวิต · แสดง portrait, ชื่อ, เลขบัตร (จาก seed), วันเกิด/อายุ, ที่อยู่, อาชีพ
- รูปในบัตรอัปเดตตามหน้าตาและวัย

**ร้านตัดผมชุมชน**
- บางขุนเทียนมี hotspot ร้านตัดผม ฿150 (ถูกกว่าในเมือง ฿300)

## 4. สถานะ (Stats)

### 4.1 หกตัวตลอดชีวิต

| Stat | ช่วง | ขึ้นเมื่อ | ลงเมื่อ | หมายเหตุ |
|---|---|---|---|---|
| **สุขภาพ** | 0–100 | ออกกำลังกาย, นอนพอ, ตรวจสุขภาพ | อายุ, OT, เหล้า, ความเครียดสะสม | 0 = ตาย |
| **ใจ** | 0–100 | ครอบครัว, งานอดิเรก, วันลา | งานน่าเบื่อ, หัวหน้า, หนี้, รถติด | 0 ติดกัน = หมดไฟ |
| **ปัญญา** | 0–100 | เรียน, อ่าน, อบรม | — (ไม่ลด ยกเว้นสมองเสื่อมตอนแก่) | ปลดล็อกตัวเลือก |
| **มนุษยสัมพันธ์** | 0–100 | สังสรรค์, ช่วยเหลือ | ปฏิเสธ, เอาเปรียบ | ปลดล็อกตัวเลือกซ่อน |
| **เงิน** | บาทจริง | เงินเดือน, OT, อาชีพเสริม | ค่าใช้จ่าย, หนี้ | — |
| **เครดิต** | 0–100 (เริ่ม 65) | จ่ายหนี้ตรงเวลา | ค้างชำระ, หนี้ท่วม | ปลดล็อกสินเชื่อ/ที่อยู่ |

> **Prototype:** เพิ่ม พลังงาน (energy) และผลงาน (kpi) สำหรับการเดิน/ทำงานรายวัน, เพิ่ม ปัญญา (smarts) และมนุษยสัมพันธ์ (social) สำหรับวัยเรียน/ความสัมพันธ์ → รวม 8 ตัว
> แนวทางอาชีพจากบทที่ 4 (มหาวิทยาลัย/อาชีวะ/ทำงานเลย) มีผลต่อเงินเดือนเริ่มต้น + โบนัสจากค่าปัญญา

### 4.2 Trait (นิสัยติดตัว)
ได้จากวัยเด็กและการตัดสินใจสำคัญ — มีผลกับค่า event
`ขยัน` `ขี้อาย` `ใจร้อน` `เจ้าเล่ห์` `ประหยัด` `ฟุ่มเฟือย` `อดทน` `แรงฮึด` `มีคอนเนคชัน`

### 4.3 การเชื่อมโยง (ทุกอย่างส่งผลถึงกัน)
ตัวอย่าง: **รับ OT 1 ครั้ง**

| ผลทันที | ผลสะสม |
|---|---|
| เงิน +3,000 | สุขภาพ −1 (สะสม) |
| พลังงาน −18 | ความสัมพันธ์ครอบครัว −4 |
| ใจ −12 | trait `ฟุ่มเฟือย`/`ขยัน` มีผลคูณ |
| ผลงาน +6 | ถ้าทำติดกัน 3 เดือน → event "หมดไฟ" |

> หลักการ: **ทุก activity ต้องมีอย่างน้อย 1 ค่าที่ลดลง** ไม่มีของฟรี

## 5. เส้นทางอาชีพ

### 5.1 สายงาน (เฟส 1: ออฟฟิศเป็นหลัก)

| สาย | ทางเข้า | เงินเดือนเริ่ม | โต | กับดัก |
|---|---|---|---|---|
| **SME** | จบปริญญา/อาชีวะ | 18,000 | เร็วถ้ารับงานทุกอย่าง | งานเกินตำแหน่ง, ไม่มีสวัสดิการ, OT ไม่จ่าย |
| **มหาชน/จำกัด** | จบปริญญา, เกรดดี | 22,000 | ตาม KPI + การเมือง | แข่งขันสูง, เลย์ออฟตามเศรษฐกิจ |
| **ข้ามชาติ** | ปริญญา + ภาษา | 28,000 | ตามใบเซอร์/ภาษา | โดดเดี่ยว, วัฒนธรรมองค์กร |
| **อาชีวะ → โรงงาน/ช่าง** | ปวช./ปวส. | 15,000 | ตามฝีมือ/ใบเซอร์ | ร่างกาย, กะกลางคืน |
| **ค้าขาย/ฟรีแลนซ์** | ทางเลือก隨時 | 0 (ผันผวน) | ตามชื่อเสียง | ไม่มีสวัสดิการ, รายได้ไม่แน่นอน |
| *รับราชการ* | *เฟส 2* | — | — | — |

### 5.2 บันไดตำแหน่ง (สายออฟฟิศ)

| ตำแหน่ง | เงินเดือน | เงื่อนไขเลื่อนขั้น |
|---|---|---|
| เด็กใหม่ (Staff) | 18,000–25,000 | — |
| เจ้าหน้าที่อาวุโส | 25,000–35,000 | ผลงาน ≥ 55, อายุงาน 2 ปี |
| หัวหน้าทีม | 35,000–50,000 | ผลงาน ≥ 70, มนุษยสัมพันธ์ ≥ 50, ผ่านโปรเจกต์ใหญ่ 1 ครั้ง |
| ผู้จัดการ | 50,000–80,000 | ผลงาน ≥ 85, การเมืองในออฟฟิศ, ใบเซอร์ |
| ผู้อำนวยการ | 80,000–150,000 | ผลงาน ≥ 95, เครือข่าย, อายุ ≥ 40 |

### 5.3 กลไกในที่ทำงาน
- **ผลงาน (KPI)** — สะสม passively ตามเวลาทำงาน และลดบางส่วนตอนประเมินปลายปี
- **การเมืองออฟฟิศ** — สายสัมพันธ์กับหัวหน้า/เพื่อนร่วมงาน ปลดล็อกหรือปิดโอกาส
- **OT** — ตัวเลือกที่ให้เงินเร็ว แต่กินสุขภาพและครอบครัว
- **ประเมินผลปลายปี** — ขึ้นเงินเดือน 0–12% + โบนัส 0–6 เดือน ตามผลงาน/การเมือง
- **เลย์ออฟ** — สุ่มตามเศรษฐกิจ/อายุ (โอกาสสูงขึ้นมากหลัง 45)

> **Prototype:** ประเมินทุก 12 เดือนจาก KPI 60% + มนุษยสัมพันธ์ 20% + ความสัมพันธ์หัวหน้า 20%
> score ≥75 + ทำงานครบ 2 ปี → เลื่อนขั้น; อายุ 45+ และ score <50 มีโอกาสถูกเลย์ออฟ

## 6. เศรษฐกิจและหนี้

### 6.1 ตัวอย่างงบเดือน (กรุงเทพฯ, เด็กใหม่)

| รายการ | บาท |
|---|---|
| เงินเดือน | +22,000 |
| ค่าเช่าห้อง | −5,500 |
| อาหาร | −6,000 |
| เดินทาง (BTS/รถเมล์/น้ำมัน) | −3,000 |
| ผ่อนรถ | −6,500 |
| หนี้บัตรเครดิต (ขั้นต่ำ) | −1,500 |
| **เหลือ** | **−500** |

> ช่วงแรกของเกมผู้เล่นจะ "ติดลบ" — นี่คือแรงกดดันที่ทำให้ต้องรับ OT หรือหาอาชีพเสริม

> **Prototype M1 ใช้ตัวเลข:** เงินเดือน 22,000 · ค่าเช่า 5,500 · เดินทาง 3,000 · ผ่อนรถ 6,500 · บัตรเครดิตขั้นต่ำ 1,500 · กยศ. 1,200 → เหลือก่อนกินใช้ 4,300/เดือน (อาหารเป็นการใช้จ่ายรายวัน)
>
> **Balance patch:** ภาษีขั้นบันได 5/8/12/17% + **ประกันสังคมลูกจ้าง 5% (เพดาน 750/เดือน)** · ค่าเช่า/ค่าน้ำไฟ (1,800/เดือน ปรับเงินเฟ้อ) + **lifestyle cost แบบขั้นบันไดตามรายได้รวม** (≤40k 12% · 40–80k 18% · 80–150k 25% · >150k 30%) **จ่ายเองที่บ้าน** ผ่านจุด “จ่ายบิลที่อยู่” — ถ้าไม่จ่ายจะทบเข้าบัตรเครดิต · ค่าเดินทางจ่ายต่อเที่ยว (รถเมล์ 15฿) · เงินเดือนรีวิวไม่เกิน `rank.max` · promotion gate ตาม rank/อายุ · เกษียณอัตโนมัติที่ 65 · ล้มละลายเมื่อค้างชำระ + ฐานะสุทธิติดลบ · ดูผล simulation ใน `docs/BALANCE.md`

### 6.2 หนี้ 4 ประเภท
| ประเภท | ดอกเบี้ย/เดือน | กำหนดชำระ | ผลถ้าค้าง |
|---|---|---|---|
| บัตรเครดิต | 2.5% | วันที่ 25 | ค่าปรับ 5%, เครดิต −3; ค้าง 2 เดือนเจ้าหนี้ตาม, 4 เดือนถูกฟ้อง |
| ผ่อนรถ | 0.6% | วันที่ 5 | ค่าปรับ 5%, เครดิต −3; ค้าง 3 เดือนรถถูกยึด |
| กยศ. | 1% | วันที่ 15 | ค่าปรับ 5%, เครดิต −3; ค้าง 4 เดือนถูกฟ้อง |
| สินเชื่อส่วนบุคคล | 1.5% | วันที่ 20 | เบิกได้ +50,000 เมื่อเครดิต ≥ 60; ค้าง 2 เดือนเจ้าหนี้ตาม, 4 เดือนถูกฟ้อง |

> **ผู้เล่นต้องจ่ายหนี้เอง** ผ่านหน้าจอการเงิน (`F`) — ระบบไม่หักจากเงินเดือนอัตโนมัติ
> จ่าย ≥ ขั้นต่ำจึงถือว่าจ่ายเดือนนั้น; ปล่อยค้างนานจะโดนค่าปรับ เครดิตตก เจ้าหนี้ตาม ยึดรถ ฟ้อง จนถึงล้มละลาย
> เงื่อนไขจบเกม: เครดิต 0 + ค้างรวม ≥ 6 เดือน หรือหนี้รวม > 500,000 → ล้มละลาย; สุขภาพ 0 → จบชีวิต

### 6.3 เครดิต (0–100)
- ≥ 70 → กู้บ้านได้, ดอกเบี้ยต่ำ
- 40–69 → กู้ได้แต่ดอกสูง
- < 40 → กู้ไม่ได้, ต้องเช่าตลอดชีวิต (ส่งผลถึงตอนจบ)

### 6.4 เงินเฟ้อและค่าครองชีพ
ราคาสิ่งของเพิ่มปีละ 2–3% แต่เงินเดือนขึ้นไม่ทันเสมอ → ความรู้สึก "ยิ่งทำงานยิ่งจน" คือส่วนหนึ่งของเกม

## 7. จังหวัดและภูมิภาค

### 7.1 เฟส 1 — กรุงเทพฯ + ปริมณฑล

| | กรุงเทพฯ | ปริมณฑล (นนทบุรี/ปทุมธานี/สมุทรปราการ) |
|---|---|---|
| ค่าเช่า | 5,000–15,000 | 3,500–7,000 |
| งาน | บริษัทเยอะ เงินสูง | โรงงาน/นิคมอุตสาหกรรม |
| เดินทาง | 1–2 ชม./วัน | 1–1.5 ชม./วัน |
| ใจ | −2 ต่อเดือน (รถติด/คนเยอะ) | −1 |

### 7.2 เฟส 2 — ภูมิภาค (ภายหลัง)

| ภูมิภาค | ไลฟ์สไตล์ |
|---|---|
| ภาคเหนือ (เชียงใหม่) | ค่าครองชีพต่ำ, งานท่องเที่ยว/ฟรีแลนซ์, ชุมชนศิลปะ |
| ภาคอีสาน (ขอนแก่น) | ครอบครัวใหญ่, เกษตร/ราชการ, กลับบ้านง่าย |
| ภาคตะวันออก (ชลบุรี) | โรงงาน/นิคม, เงินดี แต่ชีวิตซ้ำซาก |
| ภาคใต้ (สงขลา/ภูเก็ต) | ท่องเที่ยว/ประมง, รายได้ตามฤดูกาล, พายุ |

### 7.3 การย้ายถิ่น (กลไกหลัก)
- ย้ายเข้า กทม. → เงินเดือนสูงขึ้น 40–80% แต่ค่าใช้จ่ายและใจแย่ลง
- ย้ายกลับบ้าน → เงินเดือนลดครึ่ง แต่ครอบครัว +, ค่าใช้จ่าย −, สุขภาพ +
- ค่าย้ายถิ่น + สูญเสียความสัมพันธ์กับเพื่อนร่วมงานบางส่วน
- **"กลับบ้านตอนพ่อแม่ป่วย"** เป็น event บังคับที่เจอได้ทุกเส้นทาง

### 7.4 เขตในเมือง (prototype)

แต่ละบล็อกของแผนที่มีสี หลังคา กิจกรรม และ event เฉพาะเขต:

| เขต | โทน | สถานที่สำคัญ | กิจกรรม |
|---|---|---|---|
| สามย่าน | นักศึกษา/หนังสือ | โรงเรียน, ร้านหนังสือ | อ่านหนังสือ/ติว |
| สีลม | ออฟฟิศ/การเงิน | บริษัท สยามเทค | คาเฟ่สกายวอล์ก |
| จุฬาฯ | มหาวิทยาลัย | โรงพยาบาล, หอสมุด | เข้าหอสมุด |
| บางรัก | บ้านเก่า/ริมน้ำ | บ้าน, ตลาดเช้า | เดินเลียบแม่น้ำ |
| ปทุมวัน | ห้าง/บันเทิง | 7-Eleven, โรงหนัง | เดินห้าง/ดูหนัง |
| สวนลุมพินี | สวนสาธารณะ | สระน้ำ, สวน | วิ่ง/แอโรบิก |
| เยาวราช | ตลาดกลางคืน/อาหาร | ร้านเหล้า, สตรีทฟู้ด | กินสตรีทฟู้ด |
| คลองเตย | ท่าเรือ/โรงงาน | ฟิตเนส, ตลาด | เดินตลาด/ช่วยงาน |

- `life.district` อัปเดตตามตำแหน่งผู้เล่น
- `src/world/districts.ts` มี `districtAt()` / `districtStyle()` สำหรับสีและ event
- event เขตใช้ `requires: { district: 'yaowarat' }` เป็นต้น
- แต่ละเขตมี **street props/decals**, **รายละเอียดดาดฟ้า** และ **แสงกลางคืน** เฉพาะ เช่น โคมเยาวราช, สกายวอล์กสีลม, บิลบอร์ดปทุมวัน
- กิจกรรมเขตมี **กลางวัน/กลางคืน** ต่างกัน (เช่น เยาวราชกลางคืน = ตลาดกลางคืน, สีลมกลางคืน = บาร์หลังเลิกงาน)
- **Milestones:** `life.milestones` แสดงความสำเร็จในหน้า `L` (งานแรก, เลื่อนตำแหน่ง, บ้าน, รถ, ครอบครัว, เกษียณ, เงินล้าน, ปลดหนี้)
- 8 เขตในตารางนี้ยังใช้ **ภาพรวมเมือง** เป็นหลัก; เขตที่มี `district scene` (ดู 7.5) จะเข้าไปเล่นในแผนที่เฉพาะของตัวเอง

### 7.5 แผนที่เฉพาะเขต (District Scene)

เมืองหลัก 40×28 ยังเป็น **ภาพรวมกรุงเทพฯ** สำหรับ debug/ฉากสร้างตัว แต่เมื่อเข้าสู่วัยทำงาน เกมจะสร้าง **แผนที่เมืองของจังหวัด/เขต/ย่านที่เลือก** (`src/world/city-maps.ts`) และเข้าเป็น `scene='district'`

| เขต | ขนาด | ธีมแผนที่ | สถานะ |
|---|---|---|---|
| บางขุนเทียน | 48×32 | coastal + canal + mangrove + factory | ✅ vertical slice |
| เยาวราช | 40×28 | market maze + shophouse | ⏳ |
| สีลม | 40×28 | CBD grid + skywalk | ⏳ |

**mapSpec** (`src/world/district-maps.ts`) เก็บ:
- `w/h`, `grid` (collision), `buildings/houses`, `roads/sidewalks`
- `water` (sea/canal/pond), `sand`, `mangroveZones`
- `trees/mangroves/props/hotspots`, `spawn`, `palette`
- `zoneRects` + `districtZone()` สำหรับ audit

**การเข้า/ออก**
- เข้า: hotspot ป้ายรถเมล์สายใต้บนแผนที่เมือง หรือปุ่มในคู่มือ `?`
- ออก: hotspot “กลับเขตลุง” หรือปุ่มในคู่มือ
- เก็บ `life.activeDistrict` ในเซฟ; `scene = 'district'` ถูกเตรียมใหม่ตอนโหลด
- debug: `?district=bangkhunthian&x=31&y=26&t=1020`

**กิจกรรมบางขุนเทียน**
- ตลาดอาหารทะเล (อิ่ม + ของสะสมอาหาร)
- ศาลเจ้า (ใจ + ครอบครัว)
- ท่าเทียบเรือ/นั่งเรือคลอง
- เดินป่าชายเลน (ปัญญา + ของที่ระลึก)
- บ่อกุ้งชุมชน / โรงงาน / ห้องเย็น / โกดัง (รายได้เสริม)
- หาดบางขุนเทียน / ร้านอาหารทะเล / อนามัย / โรงเรียนชุมชน

**อาร์ต**
- ทะเลไล่เฉด + โฟม + คลื่นเคลื่อนไหว + ประกาย
- คลองพร้อมตลิ่งโคลน ผักตบชวา และสะพานไม้
- ป่าชายเลน (รากโผล่), บ่อกุ้ง, ท่าเรือไม้, เรือโยก, ควันโรงงาน, ไอน้ำตลาด
- ไฟกลางคืนแบบ additive: ตะเกียงศาลเจ้า ตลาด ไฟถนน โรงงาน

> กฎ: object ทุกตัวต้องอยู่ในโซนที่อนุญาต และต้องผ่าน `__districtAudit()`

### 7.6 ลำดับชั้นภูมิศาสตร์: จังหวัด → เขต/อำเภอ → ย่าน

- ข้อมูลอยู่ใน `src/data/geo.json` + `src/world/geo.ts`
- ใช้คำ **“เขต”** เฉพาะกรุงเทพฯ; จังหวัดอื่นใช้ **“อำเภอ”**
- **“ย่าน”** เป็นชื่อเชิงสังคม/เศรษฐกิจ (ไม่ใช่หน่วยราชการ)
- 8 จังหวัด × 4–8 เขต/อำเภอ × 2–4 ย่าน (กรุงเทพฯ 8 เขต, จังหวัดอื่น 4 อำเภอ)
- สร้างตัวละคร: ชื่อ/เพศ/จังหวัด → เลือกเขต/อำเภอ → เลือกย่าน → ภูมิหลัง → ความฝัน
- ย้ายถิ่น: จังหวัด → เขต/อำเภอ → ย่าน → จ่าย ฿10,000/ปี
- ย่านมีผลต่อ:
  - ค่าเช่า (`rent` 0.60–1.55)
  - เงินเดือนเริ่มต้น (`salary` 0.78–1.20)
  - ไลฟ์สไตล์/event ในอนาคต
- เก็บในเซฟ: `life.khet`, `life.khetName`, `life.neighborhood`, `life.neighborhoodName`
- `life.district` เดิมยังใช้เป็นโซนแผนที่เมือง 8 โซน เมื่อย่านอยู่ในกรุงเทพฯ
- ตรวจด้วย `__ol.geoAudit()` (id ไม่ซ้ำ, zone ถูกต้อง, ครบ 8 จังหวัด)

### 7.6.1 แผนที่เมืองที่สร้างตามจังหวัด/เขต

- `getCityMap(province, khet, hood)` สร้าง mapSpec 40×28 จาก seed ของ province+khet+hood
- ความต่าง:
  - palette ตามภาค (กลาง/เหนือ/อีสาน/ตะวันออก/ใต้)
  - แหล่งน้ำ: คลอง/บ่อ/ทะเล ตามจังหวัด
  - โครงถนน: บางจังหวัด/เขตตัดถนนสายรองออก (แนวตั้ง/แนวนอน) ทำให้ผังไม่เหมือนกัน
  - ตำแหน่งบ้าน/ต้นไม้/props แบบ seeded
- hotspot หลักในทุกแผนที่: บ้าน, ออฟฟิศ, ร้านสะดวกซื้อ, ตลาด, โรงพยาบาล, ร้านตัดผม, ร้านเสื้อผ้า, ฟิตเนส, สถานีขนส่ง, ร้านอาหาร, วัด/ศาลเจ้า, สวน/หาด
- เข้า-ออกบ้าน/ออฟฟิศ/สถานี แล้วกลับจุดเดิมของแผนที่นั้น (`mapReturnPoints`, `interiorSource`)
- เก็บ `life.activeMap` (แผนที่หลัก) และ `life.currentMap` (`city:`/`district:`) ในเซฟ
- **ความหนาแน่น (`spec.style.archetype`)** — การประมาณของเกม (ดู `docs/research/city-streetscape-art.md` §8):
  - `urban`: เขตกรุงเทพฯ ทั้งหมด (ยกเว้นบางขุนเทียน) + หาดใหญ่ → ตึกแถวเรียงหน้าถนน ~30 หลัง, พื้นคอนกรีต/ลานจอด, ต้นไม้ ≤14 ในหลุมปลูก
  - `town`: อำเภอเมือง/อำเภอทั่วไป → ตึกแถวบางช่วงตามถนนหลัก + บ้านเดี่ยว, หญ้าผสมลานคอนกรีต/ดิน, ต้นไม้ ≤34
  - `rural`: นาทวี, น้ำพอง, ชุมแพ, บ้านไผ่, แม่ริม → บ้านเดี่ยว/บ้านไม้ยกใต้ถุน, ไหล่ทางคอนกรีต (ไม่ปูกระเบื้อง), ต้นไม้ ≤60
- **ภาค (`style.region`)** เลือกต้นไม้ (มะพร้าวภาคใต้/ตะวันออก/ชายทะเล, กล้วยชนบท) และบ้านไม้ยกใต้ถุน (เหนือ/อีสาน/ใต้)
- **วัด (`style.wat`)**: วัดไทยหลังคาซ้อน 3 ชั้น+ช่อฟ้า / ล้านนาหลังคาต่ำกว้าง (เชียงใหม่) / ศาลเจ้าจีน (สัมพันธวงศ์)
- **บ้าน (`HouseSpec.kind`)**: `shophouse` ตึกแถว · `house` บ้านเดี่ยวหลังคาปั้นหยา (ไม่มีปล่องไฟ) · `stilt` บ้านไม้ยกใต้ถุน
- **props ใหม่**: `power` เสาไฟฟ้าคอนกรีต + มัดสายหย่อนระหว่างเสา, `spirit` ศาลพระภูมิ (โซน green), `moto` มอเตอร์ไซค์จอด, `win` วินมอเตอร์ไซค์เสื้อกั๊กส้ม, `cart` รถเข็นร่ม (sidewalk)
- **ภาพ**: วาดใน `src/render/city-map-art.ts` (+ `city-buildings.ts`, `city-props.ts`) แยกจาก `buildDistrictArt` ของบางขุนเทียน
  - เลเยอร์กลางวัน: หน้าต่างเป็นกระจกมืด ไม่มีไฟค้าง
  - เลเยอร์กลางคืน: หน้าต่าง/ป้าย/หน้าร้านเรืองแสง วางทับหลัง night tint ด้วยความทึบ `clamp((tint−0.08)/0.5)` + แสงฟุ้งจาก `art.lights`
  - ทางม้าลาย/เส้นหยุด/สะพาน คำนวณจากจุดตัดถนน∩ถนน และถนน∩น้ำ จริง; ขอบทางขาว-แดงใกล้แยก, ขาว-เหลืองหน้าป้ายรถเมล์/ตลาด
- ข้อจำกัดปัจจุบัน: ผังถนน/บล็อกยังเป็นกริดเดียวกันทุกเขต — ขั้นต่อไปคือ layout archetype ต่อเขต (market maze/CBD/campus/lakeside/coastal)

## 8. ความสัมพันธ์และครอบครัว

### 8.1 แกนความสัมพันธ์ 4 แกน
`หัวหน้า` · `เพื่อนร่วมงาน` · `ครอบครัว` · `คู่รัก`

แต่ละแกนมีผล:
- หัวหน้า ≥ 70 → โอกาสเลื่อนขั้น +, event ดี
- เพื่อนร่วมงาน ≤ 30 → ถูกปัดงาน/ใส่ร้าย, ใจ −
- ครอบครัว ≤ 30 → event หนัก (พ่อแม่ตัดขาด, ห่างเหิน)
- คู่รัก ≥ 70 → แต่งงาน; ≤ 20 → เลิกรา

### 8.2 เหตุการณ์ชีวิต
- แต่งงาน (ค่าใช้จ่าย 100,000–500,000 ตามฐานะ)
- มีลูก (รายจ่าย +8,000–15,000/เดือน, ใจ +, เวลาส่วนตัว −)
- พ่อแม่ป่วย (ต้องเลือก: ส่งเงิน / ลางาน / ย้ายกลับ)
- งานศพญาติ (ต้องไป + ใส่ซอง 1,000–5,000)
- เพื่อนสนิทถูกเลย์ออฟ (เลือกช่วยหรือไม่)

> **Prototype:** แต่งงาน +3,000/เดือน · มีลูก +8,000/เดือน · บ้านลดค่าเช่าเหลือ 1,500/เดือน · ไม่มีรถ/รถถูกยึดค่าเดินทาง 1,200/เดือน

### 8.3 ค่าใช้จ่ายทางสังคม
ซองงานแต่ง/งานศพ/งานบวช — ระบบที่คนไทยเข้าใจดี และเป็นแรงกดดันทางการเงินที่แท้จริง

## 9. ระบบเหตุการณ์ (Event System)

### 9.1 ประเภท
1. **Event ประจำเดือน** — เกิดตามรอบ (เงินเดือนออก, ประเมินผล, ภาษี)
2. **Event สุ่ม** — ตามน้ำหนักและเงื่อนไข
3. **Event ตามเงื่อนไข** — เช่น หนี้ > 50,000 → เจ้าหนี้โทรมา
4. **Event ตามฤดูกาล** — สงกรานต์, ตรุษจีน, ปีใหม่, เปิดเทอม
5. **Event เนื้อเรื่องหลัก** — ตามบทชีวิต (บังคับเกิด)

## 10. ความตายและบทสรุป

### 10.1 สูตรความเสี่ยง (สุ่มทุกเทิร์น)
```
baseRisk = max(0, (age - 45)) * 0.0012
healthRisk = (100 - health) * 0.0015
oldAgeRisk = age >= 80 ? (age - 80) * 0.004 : 0
totalRisk = (baseRisk + healthRisk + oldAgeRisk) * max(0.6, months / 12)
```
- ทุกเทิร์นสุ่ม `random() < totalRisk` → เกิดเหตุร้าย (ป่วยหนัก/อุบัติเหตุ)
- เหตุร้ายอาจทำให้สุขภาพลดฮวบ หรือตายทันที (โอกาสต่ำ)
- **แจ้งเตือนล่วงหน้า**: ถ้าสุขภาพ < 30 จะมี event "ร่างกายส่งสัญญาณ" ให้โอกาสแก้ตัว

### 10.2 หน้าจอสรุปชีวิต (Death Screen)
- ปีเกิด–ปีตาย, อายุ
- ตำแหน่งสุดท้าย, อาชีพ
- ทรัพย์สิน / หนี้คงเหลือ
- ครอบครัว: แต่งงานไหม, ลูกกี่คน, ใครมาส่ง
- ความฝัน: สำเร็จ / ไม่สำเร็จ
- **ประโยคสุดท้าย** — เขียนจาก stat จริง เช่น
  - `health` สูง + `family` สูง → "คุณจากไปอย่างสงบ มีคนที่รักอยู่ข้าง ๆ"
  - `money` สูง + `family` ต่ำ → "งานศพมีคนมาเยอะ แต่ไม่มีใครที่รู้จักคุณจริง ๆ"
  - `heart` ต่ำสะสม → "คุณทำงานหนักมาตลอด จนลืมว่าตัวเองอยากอะไร"

### 10.3 ตอนจบ 8 แบบ
1. เกษียณอย่างสงบ
2. รวยแต่ตัวคนเดียว
3. หมดไฟกลางทาง
4. หนี้ท่วมจนตาย
5. ลาออกไปทำของตัวเอง
6. ติดคดี (ถ้าโกง/คอร์รัปชัน)
7. สุขภาพพังก่อนเกษียณ
8. ตายก่อนวัยอันควร (อุบัติเหตุ/โรค)

  - เริ่มใหม่เมื่อมีเซฟ = เขียนทับเซฟเดิม
  - `prefers-reduced-motion` ลดความเร็วแอนิเมชัน

### 11.2 ลำดับการเล่น 1 ช่วงเวลา (Hybrid)
1. ดูสถานะ + ข่าว
2. ทำกิจกรรมได้ตามงบของช่วง (3/5/7/9 ครั้งสำหรับ +1/+3/+6/+12) กิจกรรมซ้ำผลลดหลั่น
3. กด **N / ปุ่มเดินเวลา** → เลือก +1 / +3 / +6 / +12 เดือน
4. เจอ event 1 อัน → เลือก → สลิปเงินเดือน (คิดตามจำนวนเดือน) → สถานะอัปเดต
5. ทุก 12 เดือนจริง → ประเมินผลปลายปี
6. กิจกรรมรีเซ็ตตามงบของช่วง (`periodMonths`) และ `activityUses` ล้างเมื่อเริ่มช่วงใหม่

### 11.2.1 Activity points + diminishing returns
| ครั้งที่ทำกิจกรรมเดิมในช่วงเดียว | ผลบวก |
|---|---|
| 1 | 100% |
| 2 | 50% |
| 3 | 25% |
| 4+ | 0% (ยังจ่ายเงิน/เสียพลังงานเต็ม) |

- ค่าลบ/ค่าใช้จ่ายไม่ลดตาม — กันการปั๊มผลบวก
- HUD แสดง `กิจกรรมช่วงนี้ x/3` และอารมณ์/อากาศ

### 11.3 หลักการ UX
- อ่านเร็ว ตัวเลขชัด ไม่ต้องเปิดเมนูซ้อน
- **ไม่มีปุ่มเดิน/ปุ่มคำสั่งถาวรบนจอ** — ใช้การแตะ/คลิกในโลก (tap-to-move + tap hotspot)

  - รองรับ safe-area ของจอมีติ่ง
- ปุ่ม `?` เดียวสำหรับคู่มือ, คีย์ลัด, และเล่นทัวร์ซ้ำ
- First-run coach tour 4 สเต็ปพร้อมไฮไลต์ (ข้ามได้)

- แอนิเมชันสั้น: แถบสถานะเลื่อน, ticker วิ่ง, ตัวเลขเด้ง

### 12.4 เสียง

## 13. สถาปัตยกรรมเทคนิค

### 13.1 Stack
- **Vite + TypeScript**
- UI: HTML/CSS (DOM) — เพราะ UI กินพื้นที่ 70%
- แผนที่: Canvas 2D (tile renderer)
- State: module state + event functions (ทยอยแยก reducer/engine)
- Save: localStorage (JSON, versioned v3)
- Build: Vite 7 + TypeScript 5 (มี `npm run dev/build`)
- ไม่ใช้ engine หนัก (Phaser) ในเฟสแรก

### 13.2 โครงโฟลเดอร์
```
OpenLife/
  index.html
  package.json
  vite.config.ts
  tsconfig.json
  docs/GDD.md
  design/mockup/         # mockup UI
  src/
    main.ts
    game.ts              # เกมหลัก (ทยอยแยกเป็นโมดูล)
    audio.ts             # SFX + procedural music
    events.ts            # JSON event compiler + ops
    event-pools.ts       # JSON event loader + requires matcher
    districts.ts         # 8 districts + districtAt/districtStyle
    audit.ts             # content/state audits
    save.ts              # save/load v3
    actions.ts           # scene entry + daily activities + work
    picker.ts            # cross-run event memory
    util.ts              # clamp/fmt/rnd
    date.ts              # calendar helpers
    world-data.ts        # buildings/trees/houses
    style.css
    data/                # chapters/backgrounds/dreams/provinces/career/finance/debts.json
  prototype/             # legacy vanilla JS (ย้อนกลับฉุกเฉิน)
  dist/                  # เอาต์พุตจาก npm run build
```

### 13.3 Data-driven
- ข้อมูลที่ designer ปรับได้อยู่ใน `src/data/*.json`: บท, ภูมิหลัง, ความฝัน, จังหวัด, อาชีพ, การเงิน, หนี้
- Event แบบ declarative อยู่ใน `src/data/events.json` + schema ที่ `src/data/events.schema.json` (season/month/chapter5/chapter8)
  - schema รองรับ `requires` (minMoney/maxHealth/minRel/parentsAlive/flag/childAge/careerTrack), `fx`, `random` branch และ `ops`
  - `ops` รองรับ stat/rel/flag/salary/rent/job/debt/ifFlag — event ที่เคยใช้ `apply()` ถูกแปลงเป็น ops แล้ว
- เป้าหมาย: ย้าย event ที่เหลือเป็น JSON schema + effect ops ครบทั้งเกม

## 16. อัปเดต v0.3 (UX overhaul + living city)

### 16.1 การสร้างตัวละคร
- แยกช่อง **ชื่อ** และ **นามสกุล** (พิมพ์เว้นวรรคได้)

- แก้กรอบแว่นให้พอดีใบหน้า (หน้า x 9–23)

### 16.2 แผนที่แบบสุ่ม + แลนด์มาร์คประจำเขต
- อาคารหลัก (บ้าน/ออฟฟิศ/ร้านสะดวกซื้อ/ตลาด/โรงพยาบาล/ร้านตัดผม/ร้านเสื้อผ้า/ยิม/สถานี/บาร์/วัด) ถูก **สุ่มตำแหน่ง** ภายในบล็อกจาก seeded RNG ต่อเขต → แต่ละเขตไม่ซ้ำกัน
- บังคับ **บ้านกับออฟฟิศอยู่คนละฝั่ง** ของแผนที่
- **แลนด์มาร์คประจำเขต** ตำแหน่งตายตัว (เช่น บางขุนเทียน = ท่าเรือประมง, เยาวราช = ศาลเจ้าจีน, บางรัก = โรงแรมริมน้ำ)

### 16.3 เข้าได้ทุกอาคาร
